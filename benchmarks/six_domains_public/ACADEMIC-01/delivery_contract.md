# ACADEMIC-01 交付合同

## 核心交付物

| 交付物 | 格式 | 必需 | 说明 |
|--------|------|------|------|
| 论文正文 | LaTeX/PDF | ✓ | 包含完整章节结构 |
| 摘要 | 中英文 | ✓ | 中文300-500字，英文150-250词 |
| 参考文献 | BibTeX | ✓ | ≥15篇，近3年≥50% |
| 图表 | PDF/PNG | ✓ | ≥3个 |

## 质量要求

### 结构完整性
- [ ] 包含摘要、引言、相关工作、方法分类、应用案例、讨论、结论
- [ ] 章节标题规范，层次清晰
- [ ] 段落长度适中（200-400字/段）

### 内容质量
- [ ] 方法分类清晰（内在vs事后）
- [ ] 技术描述准确（LIME、SHAP等）
- [ ] 应用案例具体（≥3个）
- [ ] 未来方向有见地

### 格式规范
- [ ] LaTeX格式正确
- [ ] 参考文献格式统一（IEEE/ACM）
- [ ] 图表清晰，有标题和引用

### 学术规范
- [ ] 无抄袭嫌疑
- [ ] 引用格式正确
- [ ] 术语使用一致
