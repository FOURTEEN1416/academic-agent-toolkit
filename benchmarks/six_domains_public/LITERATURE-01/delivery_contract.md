# LITERATURE-01 交付合同

## 核心交付物

| 交付物 | 格式 | 必需 | 说明 |
|--------|------|------|------|
| 综述文档 | Markdown/LaTeX | ✓ | 包含完整章节结构 |
| 摘要 | 中英文 | ✓ | 中文200-400字，英文100-200词 |
| 参考文献 | BibTeX | ✓ | ≥20篇，近3年≥40% |
| 图表 | PDF/PNG | ✓ | ≥2个 |

## 质量要求

### 结构完整性
- [ ] 包含摘要、引言、方法分类、应用案例、讨论、结论
- [ ] 章节标题规范，层次清晰

### 内容质量
- [ ] 方法分类清晰（隐私/通信/异构）
- [ ] 技术描述准确
- [ ] 应用案例具体（≥3个）

### 学术规范
- [ ] 引用格式正确
- [ ] 术语使用一致
