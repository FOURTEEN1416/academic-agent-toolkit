# comp-modeling P0 基准 — 建模求解能力验收

## 任务描述

本基准测试评估数学建模竞赛智能体的**建模求解能力**。智能体读取赛题上下文摘要（共享单车调度优化，3 个子问题），为每个子问题建立数学模型并撰写建模求解报告，包括数学公式、参数含义、前提条件讨论，以及按能力清单（P1-C1 等）标注建模方案。

## 输入

- `fixtures/problem_context.md` — 赛题上下文摘要（引用上游 comp-prob-analysis 基准的完整题目）

## 验收方式

```powershell
python evaluate.py <工作区路径>
```

工作区路径应包含智能体产出的文件：
- `MODELING_REPORT.md` — 建模求解报告（3 个子问题全覆盖）

## 评分项与最低要求

| 评分项 | 最低要求 |
|--------|---------|
| 文件存在性 | `MODELING_REPORT.md` 存在 |
| 子问题覆盖 | ≥ 3 个不同子问题（"问题一/问题二/问题三" 或 "### 问题 N" 标题） |
| 能力认领 | ≥ 3 条能力项（`P1-C1`/`P2-C1`/`P3-C1` 等模式，去重） |
| 数学公式 | ≥ 2 处 `$` 或 `$$` 包裹的 LaTeX 公式 |
| 符号说明表 | 含 "符号" 或 "Symbol" |
| 最小大小 | MODELING_REPORT.md ≥ 2000 字节 |

所有检查项通过即 `all_pass: true`，评分脚本退出码 0；否则退出码 1。

## 许可

本基准数据为合成数据，仅供内部验收测试使用。
