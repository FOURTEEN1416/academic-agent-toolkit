# P03 区域经济发展综合评价（合成样例）

评价 10 个省份的经济发展质量，给定 6 项指标（GDP、人均收入、失业率、研发投入比、绿化率、通胀率）。
要求：①指标同向化与无量纲化 ②确定权重 ③给出综合得分与排名 ④敏感性分析。

## 输入数据
- `data/indicators.csv`: province,GDP(亿元),income(元),unemployment(%),RD(%),green(%),cpi(%)

## 交付要求（comp_problem_analysis）
1. 拆解为：数据预处理 + 同向化 + 赋权 + 综合 + 敏感性。
2. 定义指标方向（正向/负向）与标准化方法。
3. 给出可选赋权法（熵权 / AHP / 主成分）。
