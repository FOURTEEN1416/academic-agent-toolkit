## 五、可视化设计规范建议

### 5.1 配色规范

#### 推荐配色方案

**方案A：标准蓝系（推荐）**
```
主色：#2E5CA8（深蓝）—— 标题、重点
辅色1：#4A90D9（中蓝）—— 数据系列A
辅色2：#7BB3E8（浅蓝）—— 数据系列B
辅助：#E8F4FC（淡蓝背景）—— 图表背景
中性：#666666（中灰）—— 副标题、注释
```

**方案B：暖色系**
```
主色：#C0392B（深红）
辅色1：#E74C3C（中红）
辅色2：#F5B7B1（浅红）
辅助：#FDEBD0（淡橙背景）
中性：#7D6608（棕黄）
```

**方案C：双色对比（适合2-3组数据）**
```
系列A：#3498DB（蓝）
系列B：#E74C3C（红）
系列C：#2ECC71（绿）
背景：#FFFFFF（白）
网格：#ECF0F1（浅灰）
```

#### 配色原则
1. **低饱和度优先**：所有数据系列色饱和度控制在30-60%
2. **对比度充足**：文字与背景对比度≥4.5:1
3. **颜色数量≤6**：单图表最多6种颜色，避免视觉混乱
4. **避免纯红/纯绿**：考虑色盲友好性，使用蓝-橙、蓝-红替代红-绿

### 5.2 图表类型建议

| 问题类型 | 推荐图表 | 说明 |
|---------|---------|------|
| 数据对比 | 柱状图/条形图 | 展示不同方案/指标的对比 |
| 趋势分析 | 折线图 | 时间序列、参数变化趋势 |
| 相关性分析 | 散点图 | 变量间关系、聚类分析 |
| 参数影响 | 热力图 | 多参数敏感性分析 |
| 流程展示 | 流程图/架构图 | 模型构建过程、算法流程 |
| 结果展示 | 雷达图 | 多维度综合评价 |
| 优化结果 | 收敛曲线 | 算法迭代过程 |
| 时空分布 | 地图/网格图 | 地理空间问题 |

### 5.3 图表布局规范

#### 尺寸建议
- **主图表**：宽度 500-800px，高度 350-600px（A4论文内）
- **全页图表**：宽度 1094px，高度 1546px（A4满版）
- **小图/插图**：宽度 200-400px，高度 150-300px

#### 布局原则
1. **图题在上，图注在下**：符合中文阅读习惯
2. **多图组合**：子图用(a)(b)(c)标注，相关图并列放置
3. **留白充足**：图表边缘留10-15%空白
4. **对齐统一**：同篇论文图表对齐方式一致

### 5.4 图例设计规范

| 位置 | 适用场景 | 说明 |
|------|---------|------|
| 右上角 | 单系列/双系列 | 不遮挡数据 |
| 右下角 | 多系列数据 | 与数据区分离 |
| 图外右侧 | 复杂多系列 | 避免干扰图表主体 |
| 底部居中 | 时间序列图 | 横向布局 |

### 5.5 字体规范

| 元素 | 字体 | 字号 | 颜色 |
|------|------|------|------|
| 图题 | 宋体/黑体 | 小四(12pt) | #242424 |
| 坐标轴标签 | 宋体 | 五号(10.5pt) | #333333 |
| 坐标轴数值 | 宋体 | 六号(9pt) | #666666 |

## 六、创新可视化建议

### 6.1 可考虑的创新方式

1. **交互式图表**：使用 Plotly 生成可交互HTML图，嵌入论文
2. **3D可视化**：对于空间优化问题，使用 pyvista/plotly 3D图
3. **网络图**：对于关系型问题，使用 NetworkX 生成
4. **动画截图**：对于动态优化过程，生成多帧图展示演化
5. **地理可视化**：对于空间分布问题，使用 Folium/Geopandas

### 6.2 配色创新方向

- **渐变色填充**：热力图、等高线图使用渐变色
- **分箱配色**：分类数据使用Qualitative colormap（如Set3, Paired）
- **连续配色**：数值数据使用Viridis/Plasma等感知均匀colormap
- **自定义配色**：根据问题主题定制配色（如环保问题用绿色系）
