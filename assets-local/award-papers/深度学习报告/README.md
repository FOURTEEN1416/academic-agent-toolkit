## 四、论文结构规范

优秀论文的标准结构：

1. **摘要**（200-300字）：问题概述+方法+核心结果
2. **问题重述**：用数学语言重新表述问题
3. **符号说明**：表格列出所有变量
4. **模型假设**：合理简化条件
5. **模型建立**：分小节对应各子问题
6. **模型求解**：算法设计+代码+结果
7. **结果分析**：灵敏度分析+误差分析
8. **模型评价**：优缺点总结
9. **参考文献**：规范引用
10. **附录**：完整代码
