## 六、摘要写作模式总结

### 6.1 标准摘要模板

```
【背景导入】（1-2句）
  随着... / 近年来... / 针对...问题

【方法描述】（3-5句）
  本文建立/提出/采用...模型/算法
  首先...其次...最后...

【结果报告】（2-4句）
  得到/求得/计算出...（具体数值）
  最优解为... / 准确率达到...

【结论总结】（1-2句）
  表明/说明/验证了...的有效性
```

### 6.2 写作建议

| 要素 | 建议 | 依据 |
|------|------|------|
| 字数 | 800-1500字 | 66.1%集中在700-900字，满分摘要平均1155字 |
| 结构 | 四要素齐全 | 62.9%为4/4完整度，平均分更高 |
| 结果 | ≥3个数值 | 优秀摘要平均2.5个，多结果增强说服力 |
| 开头 | 背景导入 | 91.9%采用，更易吸引评审注意力 |
| 结论 | 明确总结 | 71%有结论，是区分优秀的关键 |

### 6.3 避坑指南

1. **避免过短**：<500字的摘要信息量不足，难以展示工作全貌
2. **避免无数值**：即使结构完整，无数值结果的摘要说服力弱
3. **避免直接切入**：直接切入型论文结构完整度普遍较低
4. **避免冗长**：>2000字的摘要有5篇，需注意信息密度
