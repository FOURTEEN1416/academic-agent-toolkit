## 一、技术背景与现有技术

### 1.1 现有技术

随着电商与即时配送需求持续增长，无人机因不受地面交通约束、机动性强，被广泛视为末端配送的解决方案之一。围绕无人机配送调度问题，现有技术大体可分为以下三类方向：

**（1）基于传统运筹优化的调度方法。** 将配送调度建模为车辆路径问题（VRP）或其变体（带时间窗的取送货问题 PDPTW 等），采用精确算法（分支定界等）或启发式算法（遗传算法、蚁群算法、模拟退火、大邻域搜索等）求解。该类方法在静态场景下可给出较优解，代表性公开来源如：CN115841286B《一种基于深度强化学习的外卖配送路径规划方法》中引用的 Li 与 Lim（2003）禁忌嵌入模拟退火算法、Bent（2006）两阶段混合算法等。

**（2）基于深度强化学习的路径规划方法。** 将配送路径选择建模为马尔可夫决策过程（MDP），采用编码器-解码器网络（如注意力-指针网络）拟合策略，以 REINFORCE 或演员-评论家框架训练。代表性公开来源：CN115841286B（注意力-指针网络求解 PDPTW）；CN119168528B《基于深度强化学习的车辆-无人机协同配送路径优化方法》（考虑动态交通流与动态需求，构建带需求过期惩罚的奖励函数）；CN119671420B《一种基于分层强化学习的车辆无人机协同调度方法》（上层 DQN 决策车辆出发、下层 PPO 分配需求、启发式层实时更新路线）；期刊论文《基于深度强化学习的无人机线路及航迹协同规划》（中国安全科学学报 2023 年第 33 卷第 8 期，DRL 生成配送线路 + A* 搜索航迹的两阶段混合算法）。

**（3）基于分层/多智能体强化学习的协同规划方法。** 将复杂任务分解为多个子任务，各子任务由一个神经网络实现，形成层次化网络体系。代表性公开来源：CN109992000A《一种基于分层强化学习的多无人机路径协同规划方法及装置》（低层方向控制、中层单机路径规划、高层多机协同控制）。

### 1.2 现有技术存在的缺点

1. 传统运筹优化方法依赖完整的环境信息与静态假设，对订单动态到达、时段性运力紧张、禁飞区临时变更等动态因素适应性差；大规模实例下求解耗时长，难以满足实时调度要求。
2. 现有深度强化学习方法多聚焦于"路径顺序"单一决策维度，将调度问题与航迹可行性割裂处理，未将无人机电量约束、起降点吞吐能力、任务时限等运行约束纳入同一决策闭环，容易出现"规划出的路线在实际电量/时限下不可执行"的问题。
3. 面向多机协同的方法多采用分层结构，层间耦合依赖人工设计，训练不稳定、收敛慢；对运行环境发生动态变化（如个别无人机故障、需求突增）时缺乏在线再调度机制。
4. 现有方法普遍缺乏对调度方案可行性的显式校验与安全兜底：一旦强化学习策略输出非法动作（电量不足仍出航、超时限、进入禁飞区等），系统没有自愈手段，工程部署风险高。

## 二、本发明所要解决的技术问题

针对上述现有技术的不足，本发明提供一种基于强化学习的无人机配送调度方法及系统，旨在解决以下技术问题：

1. 在订单动态到达、运力与电量约束随时间变化、禁飞区临时调整等动态环境下，实现无人机配送任务与航线的实时联合调度；
2. 将电量约束、任务时限、起降点吞吐、空域安全约束纳入强化学习决策的同一闭环，保证调度策略输出在物理上可执行；
3. 在策略输出非法动作（电量不足、超时限、进入禁飞区）时，提供确定性规则兜底与在线修复，保证系统运行安全；
4. 通过"离线训练 + 在线微调"机制，使模型在运行环境变化后无需完全重训即可快速适应，降低部署成本。

## 三、本发明技术方案的详细阐述

### 3.1 背景

本方案面向配送中心运营的无人机末端配送场景。配送中心持有若干架无人机，每架无人机具备最大续航距离、最大载重、起飞与降落时间等属性；订单携带取送点位置、体积重量、期望送达时限等属性；空域存在禁飞区（可随时间变化）。调度系统在每一调度时刻观测全局状态，决定"哪个任务分配给哪架无人机、以何种顺序访问哪些节点、按什么航迹执行"，并使总成本（能耗、超时惩罚、起降损耗）最小、任务准时完成率最高。

### 3.2 系统框图

<!-- ![系统架构图](figures/fig_architecture.png) -->

系统由以下层次构成：**数据接入层**（订单流、无人机状态遥测、空域与禁飞区信息、气象信息）→ **状态编码层**（特征归一化、图嵌入编码）→ **决策层**（离线训练的强化学习调度策略网络 + 确定性规则兜底引擎）→ **执行与反馈层**（航迹生成、可行性校验、执行状态回灌）。决策层输出经可行性校验后下发执行；校验不通过时由兜底引擎修复。

### 3.3 模块功能说明

1. **数据接入模块**：对接订单系统、无人机遥测链路、空域管理系统，汇聚订单请求、无人机电量/位置/任务状态、禁飞区多边形等输入，经清洗与时间对齐后输出标准化的调度输入帧。
2. **状态编码模块**：将订单特征（位置、重量、时限剩余）、无人机特征（电量、载重余量、当前位置）、空域特征（禁飞区、风速风向）归一化并编码为固定维度的观测向量，供策略网络使用；对订单与无人机的配对关系采用图注意力编码，捕捉高维耦合。
3. **调度决策模块**：基于演员-评论家架构的强化学习策略网络，输入观测向量，输出调度动作（任务-无人机指派与访问顺序）；动作空间为"指派矩阵 + 顺序索引"，由带掩码的 softmax 保证合法输出。
4. **可行性校验与兜底模块**：对策略输出逐项校验电量可行性、时限可行性、载重可行性、空域安全；任一项不满足时按确定性优先级规则修复——依次尝试换机指派、拆单重派、超时降级（转入人工/地面运力），并记录修复原因用于后续训练样本加权。
5. **航迹生成模块**：对通过校验的任务序列，调用航迹规划器（A* 或 Dubins 曲线）生成避障航迹，输出起飞时间、途经点、预计落地时间。
6. **在线学习模块**：采集执行反馈（实际能耗、实际到达时刻、超时与否、修复事件），写入经验回放池；按周期用最近经验对策略网络做小步长微调（在线 PPO 更新），同时用修复事件构造负样本强化约束感知。
7. **监控与告警模块**：实时呈现机队状态、调度方案甘特图、约束违例统计；异常时触发人工介入。

### 3.4 系统流程说明

调度主流程如下：**步骤 S1** 数据接入模块按调度周期（例如每 30 秒或事件触发）生成调度输入帧；**步骤 S2** 状态编码模块对输入帧编码得到观测向量；**步骤 S3** 调度决策模块输出候选调度动作；**步骤 S4** 可行性校验与兜底模块逐项校验并修复，得到可行调度方案；**步骤 S5** 航迹生成模块为可行方案生成航迹与时刻表；**步骤 S6** 调度方案下发执行，执行结果回灌在线学习模块；**步骤 S7** 在线学习模块按需微调策略网络后返回 S1 进入下一周期。当出现"新订单到达 / 无人机返航 / 禁飞区变化 / 电量异常"四类触发事件之一时，立即唤醒一次调度周期（事件驱动），保证响应实时性。

#### 3.4.1 符号与公式

| 符号 | 含义 | 量纲/取值范围 |
|------|------|---------------|
| \(\mathcal{T}=\{1,\dots,N\}\) | 订单集合 | 无 |
| \(\mathcal{D}=\{1,\dots,M\}\) | 无人机集合 | 无 |
| \(E_{i}\) | 订单 \(i\) 的货物体积当量 | kg（或体积单位） |
| \(W_{j}\) | 无人机 \(j\) 最大载重 | kg |
| \(R_{j}^{\max}\) | 无人机 \(j\) 最大续航距离 | km |
| \(e_{j}(t)\) | 无人机 \(j\) 在时刻 \(t\) 的剩余电量（折算续航） | km |
| \(r_{i}\) | 订单 \(i\) 的期望送达时限剩余 | min |
| \(d_{k,\ell}\) | 节点 \(k\) 与节点 \(\ell\) 之间的规划航距 | km |
| \(\pi_{\theta}\) | 策略网络参数 \(\theta\) 的调度策略 | 无 |
| \(Q_{\phi}\) | 评论家网络参数 \(\phi\) 的价值函数 | 无 |
| \(a_{t}\) | 时刻 \(t\) 的调度动作（指派矩阵+顺序） | 无 |
| \(s_{t}\) | 时刻 \(t\) 的观测状态向量 | 无 |
| \(r_{t}\) | 时刻 \(t\) 的即时奖励 | 无 |
| \(\gamma\) | 折扣因子 | \([0,1)\) |
| \(\lambda_{\mathrm{late}}\) | 超时惩罚系数 | 无 |

调度问题表述为：在每一调度时刻 \(t\)，策略 \(\pi_{\theta}(a_{t}|s_{t})\) 输出动作 \(a_{t}\)，系统执行后转移至 \(s_{t+1}\) 并得到奖励：

\[
r_{t}=-\sum_{j\in\mathcal{D}}\alpha_{j}\cdot\Delta e_{j}-\sum_{i\in\mathcal{T}}\lambda_{\mathrm{late}}\cdot\max(0,\,r_{i}^{\text{delivered}}-r_{i})-\beta\cdot\mathbf{1}[\text{起降次数超限}]
\]

其中 \(\Delta e_{j}\) 为无人机 \(j\) 本次动作的能耗（按航距折算），\(\alpha_{j}\) 为其能耗权重，\(r_{i}^{\text{delivered}}\) 为订单 \(i\) 实际送达时刻对应的时限剩余，\(\beta\) 为起降吞吐超限惩罚。策略网络与评论家网络按近端策略优化（PPO）目标联合训练：

\[
L^{\text{clip}}(\theta)=\mathbb{E}_{t}\left[\min\left(\rho_{t}(\theta)\hat{A}_{t},\ \operatorname{clip}(\rho_{t}(\theta),1-\varepsilon,1+\varepsilon)\hat{A}_{t}\right)\right]
\]

其中 \(\rho_{t}(\theta)=\pi_{\theta}(a_{t}|s_{t})/\pi_{\theta_{\text{old}}}(a_{t}|s_{t})\) 为重要性采样比，\(\hat{A}_{t}\) 为优势估计，\(\varepsilon\) 为裁剪系数。

## 四、与现有技术相比的优点

1. 调度与航迹联合决策：将电量、时限、载重、空域约束纳入同一强化学习闭环，输出即物理可执行方案，克服现有方法"先规划后校验、不可行再返工"的低效路径。
2. 显式可行性校验与确定性兜底：策略输出非法动作时有规则级修复链（换机→拆单→降级），保证任何时刻都有可行解下发，工程部署安全性高。
3. 事件驱动 + 周期驱动的双模调度：对订单到达、返航、禁飞区变化等事件即时响应，兼顾系统吞吐与调度实时性。
4. 离线训练 + 在线微调：环境变化后无需全量重训，仅以最近经验与修复事件做小步长更新即可适应，训练成本低、鲁棒性强。

## 五、技术关键点和欲保护点

1. 将电量、时限、载重、空域四类运行约束显式编码进强化学习状态空间与奖励函数，并与调度动作输出构成单一决策闭环的实现方式（具体见 3.4.1 的奖励函数与状态定义）。
2. 带掩码的指派-排序联合动作空间设计，及其与演员网络输出的对应关系。
3. 可行性校验与确定性规则兜底的级联修复策略（换机指派、拆单重派、超时降级的优先级顺序及其触发条件）。
4. 事件驱动与周期驱动相结合的双模调度触发机制，及四类触发事件的判别规则。
5. 基于执行反馈与修复事件的在线微调方法，及修复事件负样本的构造与加权方式。

## 六、其它（实施例、技术效果、参数示例）

**实施例 1（基础实施例）**：某配送中心配置 5 架无人机，续航折算 20–30 km，载重上限 3 kg。仿真环境含 60 个随机订单（时限 15–60 min）、2 个禁飞区。离线训练 5×10⁵ 步后部署：任务准时完成率由启发式基线（先到先服务 + 最近插入）的 71% 提升至 92%；总能耗下降 18%；平均调度响应时间 < 1 s。上述参数仅为例示，不作为权利要求限制。

**实施例 2（兜底生效场景）**：运行中 1 架无人机电量异常（续航跌至 3 km），策略网络输出将其指派给 8 km 外订单的非法动作。可行性校验模块判定电量不足，触发"换机指派"：将该订单改派至另一续航充足无人机，同时将异常机标记为待返航；若机队整体运力不足，则触发"超时降级"转地面运力，并在经验回放池中为该样本附加约束违例权重，后续微调自动压低此类非法输出概率。

**实施例 3（在线微调）**：运营区域新增临时禁飞区后，连续 200 个调度周期内收集 3×10³ 条含禁飞区避让的经验样本，以 3×10⁻⁴ 学习率对策略网络做 500 步小步长更新，模型在 20 分钟内恢复至禁飞区变更前的准时率水平，无需全量重训。
