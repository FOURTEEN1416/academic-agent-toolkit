## 二、逐篇要点

### 01 顶刊配色24——LPH（柳叶刀公共卫生）
- 本期为 GBD 2023 道路伤害研究（DOI: 10.1016/S2468-2667(26)00141-6），图卡展示顶刊地图类图形的**分级色带 + 不均衡表达**。
- 追踪点：该系列已到第 24 期，是持续更新的"顶刊配色样本流"，可按期收集。

### 02 Codex + scientific-visualization skill（最有方法论价值）
- K-Dense-AI/scientific-agent-skills 的 `scientific-visualization` skill 配合 Codex 复刻 Rougier《Scientific Visualization》BSD 代码，四样例（振荡曲线/边缘分布散点/贝塞尔函数/极坐标方向分布）。
- **Agent 绘图纪律五条**（本仓 engine 门禁与此高度共振）：
  1. 代码+数据一起交给 agent，**禁止看图猜数值**；
  2. 合成/演示数据必须在图注显式申报（"固定随机种子的合成演示"）；
  3. 同时导出 **PNG + 可编辑 SVG + 运行记录**（随机种子/参数/原代码路径/修改记录）；
  4. 导出后**缩到目标阅读宽度复查**（字号、遮挡、背景、尺寸）；
  5. 不添加不存在的统计结论；颜色不能承担全部区分任务（须有线型/形状冗余编码）。
- 提示词范式：逐图给"参考源文件+参数+能改什么+不能改什么+导出清单"的完整约束，而非"帮我画好看点"。
- 依赖降级经验：外部 LaTeX/字体缺失时改用 Matplotlib 自带数学文字，保住可运行与矢量输出。

### 03 渐变色质感图形（R/ggplot2）
- 渐变色的**合法语义**：编码数值强度/流向（桑基流宽与强度、维恩重叠度、背景条带分层引导），**不是**分类区分手段。
- 技术要点：图形外部渐变背景须 `coord_cartesian(clip = "off")`；轴标签区渐变背景用 legendry 包。
- 对科研图的启示：渐变是"质感"来源但用在不承载语义的位置（背景/装饰带），承载语义的要素仍用离散色觉友好色——这与本仓"概念图/数据图分家"红线互补。

### 04/06 Origin 官方模板图库（19 类）
- Origin 2024/2025 `Help → Learning Center` 自带数百个官方模板：3D 柱状/3D 散点彩带墙体/3D 曲面/面积/箱线小提琴/分类专用/柱状条形/等高线云图/金融/函数/线+符号/地理地图/多面板/多坐标轴/饼环/极坐标/专业特种/统计/瀑布。
- 价值：**19 类图型的顶刊构图范式视觉参照集**——正是 09-10 外部输入盘点中记"未落地：图型映射"的现成素材。
- 注意：吸收**构图**不吸收**默认配色**（Origin 模板配色不保证色觉友好/印刷安全）。
- ⚠️ 两篇均为营销软文，"扫码发 204 领安装包"是第三方盗版引流，勿扫码勿传播。

### 05 圆形树状网络图（SCIPainter，含完整 ggraph 代码）
- **边色继承末端节点**（`geom_edge_diagonal(aes(color=edge_class))` + `scale_edge_color_manual` 与节点同一套配色）→ 网络图实现"自带图例"，减少图例面板；边配 alpha≈0.5 弱化，视觉焦点让给叶子节点。
- 径向标签防裁剪三件套：`theme_void()` + `coord_fixed(clip="off")` + 大 plot.margin；叶子标签角度公式 `-((-node_angle(x,y)+90)%%180)+90`、位置 1.06 倍半径外推。
- 反面教材点：文中的自定义配色（#80d52b 荧光绿/#fa0aa1 荧光洋红）**不通过色觉友好与印刷检查**——恰好论证了配色必须过 palette 校验而非手拍。
