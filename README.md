# Academic Agent Toolkit

An academic Agent toolkit for mathematical modeling competitions, academic papers, literature and research, course and research materials, intellectual-property materials, and figures and document production.

## Start Here

Open `D:\Desktop\数模竞赛` in OpenCode Desktop, then directly describe the academic task you need completed and provide the relevant materials.

OpenCode Desktop is the only officially supported v1 host and the only recommended user entry. The system asks only for information that materially changes the delivery route, then carries out local work in the same session. It does not depend on the `opencode` CLI being present on the system PATH. **不依赖 `opencode` CLI。**

## Current Boundary

- The 2026 CUMCM work is a validation scenario, not the product definition.
- Existing skills and scripts are not all formal released capabilities.
- Public-core/private-extension inventory, capability contracts, benchmarks, licensing, provenance, and formal release acceptance are still being established.
- Actions that use keys or potentially paid APIs, send materials outside the workspace, overwrite or delete files, or make irreversible remote changes require confirmation in the OpenCode conversation.
