## 题型规律速查

### 优化类（35%）
- 历年题：2020B / 2021B / 2022B / 2023A / 2023B
- 常用方法：LP/IP / GA / PSO / 强化学习
- 国一加分项：自适应参数 / 多目标 Pareto

### 预测类（20%）
- 历年题：2020C / 2021A / 2021C / 2022C
- 常用方法：ARIMA / LSTM / XGBoost
- 国一加分项：Attention / 混合模型 / 集成学习

### 评价类（15%）
- 历年题：2022C / 2024C
- 常用方法：AHP / TOPSIS / 熵权法
- 国一加分项：动态权重 / 主客观结合

### 统计类（12%）
- 历年题：2020C / 2021A / 2022A / 2023C
- 常用方法：回归 / Lasso / 贝叶斯
- 国一加分项：显著性 + 残差诊断

### 机理类（10%）
- 历年题：2020A / 2022A / 2023A / 2024A
- 常用方法：微分方程 / Runge-Kutta
- 国一加分项：参数识别 + 灵敏度

### 图论类（8%）
- 历年题：2021B / 2022B
- 常用方法：Dijkstra / Floyd / 启发式
- 国一加分项：复杂网络 + 鲁棒性

## 创新点查重清单

> 这些方法在国赛中已经被用烂了，纯用 = 没创新
- ❌ 纯 GA / PSO / SA（无改进）
- ❌ 纯 LSTM（无 Attention）
- ❌ 标准 ARIMA（无季节性分解）
- ❌ 标准 AHP（无一致性修正）
- ❌ 单熵权法（无组合赋权）
- ❌ 标准 XGBoost（无特征工程）

> 国一常见"加分项"创新
- ✅ 改进启发式（自适应参数 / 多目标 Pareto）
- ✅ 混合模型（CNN-LSTM / ARIMA-LSTM）
- ✅ 注意力机制 / Transformer
- ✅ 迁移学习 / 预训练
- ✅ 多模型融合（集成学习 / 模型平均）
- ✅ 博弈论组合
- ✅ 系统动力学（流图 + 反馈环）
- ✅ 元胞自动机
- ✅ 实际数据验证
- ✅ 政策建议
- ✅ 灵敏度分析
- ✅ 地图可视化
