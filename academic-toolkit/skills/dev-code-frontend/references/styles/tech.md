# 设计风格：科技感（Tech / Developer）

适合开发者工具、技术平台、数据/监控类产品。高对比、深色、几何、锐利、专业。

## daisyUI 主题
`data-theme="business"`（或 `dark`）。深色底为主。

## 配色原则
- 近黑画布（不用纯黑 #000，用 #0a0a0c 这类）+ 高对比亮文字。
- 一个鲜明科技色（青/蓝/紫）做强调，用在关键交互和数据高亮。
- 表面用"深浅阶梯"（surface-1/2/3）拉层次。

## 字体层次
- 无衬线（Inter / Geist），标题可用等宽感的字重对比。
- 代码/数据用等宽字体（JetBrains Mono / Geist Mono）。
- 标题大字号 + 负字距，正文清晰锐利。

## 组件规格
- 圆角偏小（4-8px），锐利利落。
- 卡片：深表面 + 细边框，hover 时边框提亮。
- 按钮：主色实心 + 清晰 hover 态；可用 `btn-outline` 做次要。
- 数据展示用 `stats`、`table`、`badge`、`radial-progress` 等突出数字。

## 间距/布局
- 紧凑而规整的网格，信息密度可略高。
- 等宽数字对齐（表格、指标）。
- 深色画布本身即留白，区块用细线分隔。

## 禁忌
- ❌ 浅色/柔和配色（与科技感冲突）
- ❌ 大圆角、卡通元素
- ❌ 低对比度导致看不清
- ❌ 纯黑 #000（用近黑更耐看）
