# 设计风格：优雅留白（Elegant / Apple-like）

适合产品展示页、作品集、高端品牌页。大留白、优雅、克制、精致。

## daisyUI 主题
`data-theme="winter"`（或 `light`）。极简浅色。

## 配色原则
- 大面积纯净白/浅灰底，极少用色。
- 强调色克制到极致（几乎只有一个中性偏冷的强调）。
- 靠留白和排版而非颜色制造高级感。

## 字体层次
- 优雅无衬线（系统 -apple-system / Inter），字重对比明显。
- 超大标题（display 级）+ 大量负字距；正文精致、行高舒展。
- 字号层次拉得很开（大标题很大，正文适中）。

## 组件规格
- 圆角适中优雅（10-14px）。
- 卡片：极浅表面，几乎无边框，靠极淡阴影/留白分隔。
- 按钮：简洁，主操作用一个克制的实心色，次要用文字按钮。
- 图片/产品图占主导，配大留白。

## 间距/布局
- **留白是主角**：区块间距极大（96px+）。
- 内容居中、窄栏、聚焦。
- 大图 + 少量文字，一屏一个焦点。

## 禁忌
- ❌ 信息拥挤、密集排布
- ❌ 多种鲜艳颜色
- ❌ 花哨边框和阴影
- ❌ 小字号堆砌（要敢用大字和大留白）
