# 校准 · 验证 · 确认（V&V）检查清单

> 逐项勾选；每项必须能指向**一个具体产物**（文件/表/图/日志），否则记为未执行。
> 无证据 = 未执行（本仓硬规则）。

## A. 验证 Verification（实现是否符合规格）

- [ ] **极限参数**：参数取 0 / 极大 / 边界值时行为合理（不产生 NaN、负库存、负人数）
- [ ] **解析解对比**：有解析解的简化场景（如 M/M/1 排队、线性增长）与仿真结果误差 < 明确阈值
- [ ] **守恒/平衡**：流量守恒、总人数守恒、能量守恒（有守恒量的问题必做）
- [ ] **时间步/事件独立性**：Δt 减半（或事件粒度细化）后结论不翻转
- [ ] **随机性复现**：同种子两次运行逐位一致；不同种子结果落同一分布
- [ ] **单元测试化小场景**：3–5 个极简场景断言通过

## B. 校准 Calibration（参数取什么值）

- [ ] 每个参数有**来源**：赛题给定 / 官方数据集 / 文献 / 合理假设（四类必须标注）
- [ ] 有数据时的拟合方法与**拟合优度**指标（R²、RMSE、对数似然）
- [ ] 参数**不确定区间**（贝叶斯后验 / 网格轮廓 / 文献范围）
- [ ] 无数据时的替代方案并**显式标注"未校准"**（不伪装精度）

## C. 确认 Validation（模型是否对得上真实系统）

- [ ] **留出集/留出情景**外推对比（不是拟合用的同一批数据）
- [ ] **基线对照**：历史均值 / 简单公式 / 无干预情景，至少一个
- [ ] 与文献同问题的结论方向一致性（若相反，给出解释）
- [ ] 结构性假设的可接受性论证（为什么可以忽略某因素）

## D. 不确定性量化 UQ

- [ ] 输入不确定 → 输出分布的蒙特卡洛传播
- [ ] 输出分布的报告形式：**均值 ± 95% 置信区间**（或中位数 + 分位数）
- [ ] 方差分解（Sobol 一阶/总阶）说明主导不确定源
- [ ] 结论对不确定区间的**稳健性判定**（翻转 / 不翻转，如实写）

## E. 报告纪律

- [ ] 论文中每个仿真数字可追到结果账本某一行
- [ ] 图表标注：N（重复次数）、误差棒含义（CI/标准差）、单位
- [ ] 未做的验证项**写在局限性一节**，不静默省略
