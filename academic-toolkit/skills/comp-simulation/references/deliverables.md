# 交付件：仿真视频与论文槽位

## 一、仿真视频（全国大学生仿真建模应用挑战赛为**必要**交付件）

### 官方规格（2026 第二届，真源见 `assets-local/contest-regs/csf/2nd_2026/`）

| 项 | 规定 |
|---|---|
| 容器 | **MP4** |
| 时长 | **原则上 ≤ 3 分钟**；建议**前 30 秒**讲作品概况 |
| 分辨率 | **≥ 1280×720** |
| 大小 | 建议 **≤ 300 MB** |
| 命名 | `题号+队伍号+fz.mp4`（例 `ACSF2600001fz.mp4`） |
| 必须包含 | ①模型界面与功能模块介绍 ②运行过程演示（录屏，关键参数/节点可特写）③结果分析与可视化（结果、数据分析过程、重要图表曲线） |
| 截止 | **2026-10-21 20:00**（比论文晚一天） |

### 脚本（3 分钟三段式）

| 段落 | 时长 | 内容 | 素材来源 |
|---|---|---|---|
| ① 概况 | 0:00–0:30 | 问题、方法名、一句结论 | 论文摘要页 + 方案总图 |
| ② 运行 | 0:30–2:00 | 界面/模块讲解 + 实机运行录屏（参数特写、关键时刻） | **真实录屏**（不得用 PPT 冒充） |
| ③ 结果 | 2:00–3:00 | 演化曲线/情景对比/敏感性图 + 管理启示 | 结果账本导出的图 |

### 链路（按可用性从高到低）

1. **真实运行录屏**（首选）：执行环境自带录屏 / OBS / `ffmpeg -f gdigrab`（Windows）/ CDP `Page.startScreencast`
   （动态网页可用 `cdp-headless-screencast` 技能）。
2. **图上动画化**：把仿真逐帧图序列 → `ffmpeg -framerate 24 -i frame_%05d.png -c:v libx264 -pix_fmt yuv420p out.mp4`。
3. **压缩到 ≤300MB**：
   ```bash
   ffmpeg -i raw.mp4 -c:v libx264 -crf 26 -preset slow -vf "scale=1280:-2" -c:a aac -b:a 128k -movflags +faststart out.mp4
   ```
4. **合规自检**（分辨率/时长/大小/容器）：
   ```bash
   ffprobe -v error -show_entries stream=width,height,codec_name -show_entries format=duration,size -of json out.mp4
   ```

### 视频红线

- 录屏中出现**姓名/学校/邮箱/工位名牌/桌面文件名** → 触发赛事匿名条款（匿名要求适用于**任何提交材料**）。演示前清理桌面与账号信息。
- 旁白/字幕与论文文字同受 AIGC 审查口径约束；当届阈值未取证（首届为 AIGC>30% 判雷同），按保守对待。

## 二、论文槽位（仿真专章）

建议结构（与 `comp-paper-zh` 主链衔接，不要另起炉灶）：

1. **问题与机理**：系统边界、主导特征、为什么选这类仿真（引 `method-selection.md` 的判据）
2. **模型规格**：五要素表（实体/规则/环境/时钟/观测量）+ 规则出处
3. **校准与 V&V**：参数来源表 + 验证记录 + 确认对照（引 `vv-checklist.md`）
4. **实验设计**：因子表、情景设定、N 与置信区间口径
5. **结果**：演化曲线（含置信带）、情景对比、敏感性排序
6. **稳健性与局限**：结论是否翻转、未做的验证项
7. **管理启示**：策略与调度方案（A 赛道成果要求的落点）

### 必出图清单（仿真特有）

- [ ] 演化曲线（多条情景 + 置信带）
- [ ] 情景对比（含基线对照）
- [ ] 敏感性排序（Sobol 一阶/总阶）
- [ ] 空间/相图/热图（有空间或二维参数面时）

图走 `paper-figure` / `figure-craft`；配色走统一注册表（色值不得自创）。

## 三、交付前检查

- [ ] 论文 PDF：摘要第一页、代码入附录且与正文同文件、无身份信息
- [ ] 承诺书独立件（签名）——**用户本人签署，AI 不代签**
- [ ] 支撑材料 zip/rar：含可运行源代码 + 数据（**源程序双落位**）
- [ ] 视频 mp4：≤3 min / ≥1280×720 / ≤300MB / 含三段内容 / 无身份信息
- [ ] 四件套命名：`题号+队伍号{,.pdf|,cns|,fj|,fz.mp4}` 形态正确
- [ ] 数值口径跨件一致（论文 ↔ 账本 ↔ 图 ↔ 视频字幕）
