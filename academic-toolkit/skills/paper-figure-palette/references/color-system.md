# 配色体系设计原理（color-system.md）

> 本文解释 paper-figure-palette v6 的每一条规则"为什么这样定"。
> 色值与参数以 `assets/palette_v6.json` 为唯一真源；本文负责原理与推导。

## 1. 出身与演化

- 源头：用户指定 8 色（参考图「科研配色提取与调色结果.json」第 2 组「夏日海滩」）。
- v5：在用户 8 色上做第一轮调整，发现发灰与墨色发浊两大问题。
- v6 定稿：**H° 一律不动**，仅调 L*（提亮）与 C*（提彩），并弃用 darken 换 deepen。
- 验收：全部 21 张论文图重生成 + 灰度打印/色盲（CVD）目检图板通过。

**演化的重要教训**：用户给的颜色是"色相语义锚"。任何自动改色脚本都不得动 H°，
否则用户会立刻觉得"这不是我选的颜色"。可调的只有明度 L* 与彩度 C*。

## 2. 结构分析（为什么恰好分成冷暖两族）

对 8 色按 H° 排序：24.0° → 42.5° → 54.6° → 74.1° → 90.8° | 139.6° → 235.9° → 245.9°。

- **最大色相间隙在 90.8° → 139.6°（隙 48.8°）**，把 8 色天然切成两段：
  暖段 5 色（黄→橙→粉）与冷段 3 色（绿→蓝）。
- 暖段等价于 ColorBrewer 的 YlOrRd 范式、冷段等价于 GnBu 范式——两者都是公认的
  多色相顺序色带，因此每族内部天然适合做**连续梯度**（色带、渐变）。
- **互补对**：TACC(54.6°) ↔ M1(235.9°) 相距 181.3°，近似真互补；
  两族锚 TMAIN(24.0°) ↔ MMAIN(245.9°) 相距 222°，属分裂互补。
  → 对立的物理量（温度↔水分、收入↔支出、A↔B）各占一族，读者无需图例即可分辨。
- **局限（必须知道）**：8 色 L* 全距仅 19.0（73.5→92.0），色相单向推进 222°，
  因此它**不是分类色板**——不能用于 6–8 个并列类别的饼图/柱状图分组。
  并列类别 ≤3 时可用两族锚 + 高亮；更多类别请补 NEU 与墨色，或换真正的分类色板。

## 3. 三个可计算的"好看"判据

### 3.1 去灰比 ratio = C* / C*max(L*, H°)

同一 (L*, H°) 下 sRGB 色域允许的最大彩度为 Cmax。实际彩度占上限的比例就是
"本可以多艳却没用满"的客观度量。**低于 0.94 的暖族色必然观感发灰**。

v6 实测：T4 0.847→0.95、M4 0.269→0.45（发灰主凶）、M1 0.720→0.95。
M4 因受"浅端角色"约束（L*=85 太亮时色域本身就窄），取 0.45 已是其浅端最优。

### 3.2 墨色对比度 4.6–5.7:1

8 色对白底对比度只有 1.3–2.1:1，远低于 WCAG 3:1 的图形下限——这就是为什么
**线条永远不能用基色**。墨色（deepen 产物）对白底 4.6–5.7:1，满足：

| 元素 | 色 | 对白底 |
|---|---|---|
| 文字 | INK `#2B2B2E` | ≈15:1 |
| 曲线/描边/标记 | 各族墨色 | 4.6–5.7:1 |
| 判据线 | CRIT `#57575A` | ≈7:1 |
| 参考线 | NEU `#B6B6B2` | ≈1.9:1（次要元素允许） |

### 3.3 灰度单调（假亮带判定）

色带/渐变转灰度后，若 L* 出现非单调回升，会出现"假亮带"。
判定口径：**累积回升 max(L* − running_min(L*)) ≤ 0.5 L***。
v6 暖族按色相排序时 T2(82.0)→TMAIN(81.0) 有 −1.5 的轻微回升，低于灰度 JND（≈1–2），
判定可接受；若改按 L* 排序反而引入 74.1°→24.0° 的色相跳变，观感损失更大——
**保留色相序是权衡后的结论，不是疏忽**。

## 4. 配色诊断顺序（用户说"不好看"时照此排查）

1. **发灰**：逐色算 ratio，暖族 <0.94 者提彩（向该 (L*,H°) 色域上限靠近，
   分步调，别一步到顶）。
2. **发闷/太重**：族锚 L* 是否低于 78 → 提亮 1–2.5 L*，同时维持族内单调。
3. **深色发浊**：搜代码里的 darken / 向黑缩放 / 黑色描边 → 全部换 deepen 或墨色。
4. **整体乱**：数色相族数。>2 族 → 砍到冷暖两族；纯装饰色 → 降级为 NEU。
5. **层次不清**：检查是否处处高亮。全图只允许 **一个** TACC 级高亮；
   次要信息一律 NEU/浅族。
6. **灰度坍塌**：跑累积回升判据；多曲线检查线型冗余是否齐全。

修完必须重跑 `scripts/palette_kit.py check`，任何一项 FAIL 不得交付。

## 5. 色带（colormap）设计规则

- 插值空间：**CIELAB 感知均匀插值**（`ramp_lab`），sRGB 直插中段会发灰、分层钝。
- 停靠点：`白 → lighten(族最浅, .58) → 族最浅 → … → 族锚 → 族最深 → 设计深端`。
- 深端必须"加深的族色"而非黑色：TEMP `#A3490D`（L*42）、MOIST `#19667F`（L*40），
  两者彩度都占色域上限 0.92——饱满但不荧光。
- 近白起点让热图低值区不糊住等值线与标注；等值线标注用深色文字 + 白描边光晕。
- 一张图只用一条色带；温度场与水分场并排时各用各的族带，靠族色区分语义。

## 6. 墨色系统（deepen）算法

```
deepen(hexc, f=0.34):
  若 hexc ∈ INK_MAP 且 f ≤ 0.36 → 返回设计墨色（逐色校核过对比度）
  否则：H° 不变，L* 下压；彩度 C = INK_RATIO(0.65) × Cmax(L*, H°)
```

为什么彩度取 0.65 而不是拉满？拉满会荧光（印刷上经常溢出色域），
0.65 恰好"够饱满又不发光"。f>0.36 时以墨色为基准继续下压 L*，
供色带更深的内插停靠点（如 `deepen(TACC, .52)` 得 L*≈32 的深橙）。

## 7. 与无障碍规范的关系

- 对比度：文字 15:1（AAA）、墨色线条 4.6–5.7:1（AA 图形）、参考线 1.9:1
  （装饰级，允许）。
- 色盲：红绿轴（M4 浅绿 ↔ 暖族）与蓝黄轴最敏感对都做了距离复核；叠加
  线型冗余后，三大色觉障碍类型下曲线均可分。
- 复核方法论源自 `palette_kit_v6`（CUMCM 工程）的独立双实现：
  **复核脚本必须独立实现色彩数学，不 import 生成脚本**——共用实现只能验自洽。

## 8. 已知边界（诚实声明）

- 浅端色（L*>87）在投影仪低对比环境可能偏淡：演示场景可把浅端角色换成族中段。
- 本板为白底设计；深色模式需整套重推（墨色反转逻辑不适用，勿直接反色）。
- 8 色不含中性灰：任何"第 9 色"需求一律先用 NEU/CRIT 解决，再考虑扩板。
