# 自检总索引（checks/_index.md）

> 每个子问题代码跑完、结果落盘（results.json + RESULTS.md）后、写稿/画图之前，立即执行本自检链。
> 仅第 1 问开始前完整读本索引一次，后续问题按此流程执行即可。
> 技术细节的判定标准一律指向 `skills/_utils/error_prevention.md` 对应章节（单一真源，本目录不复制其内容）。

## 三步流程

**第 1 步 · 必读（所有题型）**

| 文件 | 用途 |
|---|---|
| [consistency.md](consistency.md) | 建模-代码契约：符号/参数/单位一致性 + METHOD_CLAIMS 对照 + claim_code_check 静态扫描 |
| [sanity_check.md](sanity_check.md) | 自动数值审查 + 9 问背景审查 + 编程 Bug 排查（末尾含统计/实证 S 区段、图论 G 区段） |

**第 2 步 · 按本问题型选读一个分类自检文件**

| 本问类型 | 读哪个 | 侧重 |
|---|---|---|
| 优化类（调度/选址/路径/分配/规划/求最优值） | [optimization.md](optimization.md) | 约束闭环 + 基线同审 + 求解分层验证 + 结构性验证 |
| 预测类（时间序列/回归/分类） | [prediction.md](prediction.md) | 泄漏检查 + 基线对比 + 时序交叉验证 + 区间校准 |
| 评价类（TOPSIS/AHP/熵权法/排名打分） | [evaluation.md](evaluation.md) | 权重来源可复现 + AHP 一致性比率 + 灵敏度 + 序保持 |
| 物理/几何（碰撞检测/动力学/ODE/SAT） | [physical.md](physical.md) | 量纲 + 守恒律 + 步长收敛 + 碰撞误检率 |
| 统计/实证/图论 | sanity_check.md 末尾 S/G 区段 | — |

**第 3 步 · 产出自检报告**

- 写 `_tmp/problem_N_check.md`，每条结论标 ✅（通过）/ ⚠️（存疑，需说明）/ ❌（不通过，必须修复后重跑）；
- 修复任何 ❌ 后必须**重新运行本问全部脚本**并重跑对应自检，禁止只改文档不改代码；
- 全部 ✅/⚠️ 后才允许进入写稿与画图步骤。

## 输出纪律（所有自检脚本通用）

自检/审计脚本遵守「规则 B」：Python 读全精度重算，但**只 print 结论**（PASS/FAIL、n_violations、max_error、最多 5 条越界定位）。禁止 print 整个数组/字典/DataFrame。

## 通用流程（所有题型）

1. 先 Read `consistency.md`（建模-代码契约 + 物理参数 + 结果区间）
2. 再 Read `sanity_check.md`（自动化数值审查 + 9 问背景审查）
3. 根据本子问题的题型, 选 Read 一个分类自检：
   - 优化类（调度/选址/路径/分配/规划/求最优值） → `optimization.md`
   - 预测类（时间序列/回归/分类） → `prediction.md`
   - 评价类（TOPSIS/AHP/熵权法/排名打分） → `evaluation.md`
   - 物理/几何类（碰撞/动力学/ODE/SAT 检测） → `physical.md`
   - 统计/图论 → `sanity_check.md` 通用检查，加本题能力清单与实际模型的专项验证；不要寻找不存在的 E/S/G 区段
4. 区分已证实错误、待核对现象和检查不可用。先定位原因：缺说明补证据，环境失败修环境，真实实现/结果错误才重算受影响算例。

## ⛔ 触发硬性修复的判定规则（不可变通）

- ✅ = 有当前版本运行证据，满足本题明确条件；仍需交代方法与局限
- ⚠️ = 经验预期之外、高分、相等目标值或排名波动等待解释现象，不是必须改答案的证据
- ❌ = 有位置与观测值的题设硬约束违例、无效结果或未完成的必要计算
- 检查不可用 = 环境、超时或解析失败；不能写成通过，也不能因此重写正确模型

边界须有题设或数学依据，考虑声明的容差与对象范围。若错误来自验证器的条件、
索引或单位，修验证器并保留依据，不强迫正确结果迎合错检查。
首次碰撞、PDE/场仿真、反问题、可靠性容量题按需读 `_utils/mechanism_accuracy_addendum.md`
中的第十六章补充，选关键答案的最小有效证据，不另建一套固定网格/多算法/多种子全量循环。

离散排班/布局、状态相关系数、近似反演、单因素实验或长期目标也按补充路由
选读 16.10—16.15。分类清单与补充命中同一检查时合并为一次，复用已有结果。
原题优先级、时间口径或适用假设尚未明确时先核对，不将目录题名、关键词或历史案例
当作本问硬失败依据；逐问保留当前证据路径，不能用“规则已读”替代验证。

**禁止的"假通过"行为**：
- ❌ 超出边界但标 ✅ 并写"已在报告中讨论" → 这是 ❌
- ❌ 超出边界但标 ✅ 并写"数学解超出物理范围" → 这是 ❌
- ❌ 超出边界但标 ⚠️ 并写"物理上可以解释" → 超出就是 ❌
- 已证实实现错误不能只讨论不修；若是验证器/交接错误，修对应项，不重跑正确求解

## ⛔ 修复循环上限

同一个子问题最多修 3 轮，且共用引擎剩余返修/时间预算，不另开第三套循环。
仍失败时保存已验证检查点、未通过条件和定位证据。只有明确属于模型问题才提出回退建议；
不得自动改 MODELING_REPORT.md、放宽题设或重启整条工作流。无依赖的其他问题可继续，
但整步骤必须如实标记未完成，不能将部分结果当全量成功。
