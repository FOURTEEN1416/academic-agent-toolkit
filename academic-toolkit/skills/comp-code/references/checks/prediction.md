# prediction.md — 预测类自检（时间序列/回归/分类）

> 目标：拦截预测任务四大翻车：数据泄漏、无基线、伪验证、区间失真。
> 配套手册：`skills/_utils/error_prevention.md` 三章（统计/回归/预测类）+ 八章（数据挖掘/机器学习类）。

## 1. 数据泄漏检查（最高优先级）

- [ ] 时间序列：训练集时间上严格早于测试集（禁止 shuffle 后随机切分时序数据）；任何滚动/ expanding 窗口验证中，特征工程（标准化、均值编码、缺失填充）在每折内独立拟合；
- [ ] 特征不含未来信息：滞后特征只用 t-1 及更早；目标编码/全局统计量在训练折内计算；
- [ ] 分组数据（同一对象多条记录）：按对象分组切分（GroupKFold），防"同一对象的记录同时在训练与测试集"；
- [ ] 标签本身可信：非代理标签（ID/文件名/行号冒充语义标签——validate_capability 应有对应断言）。

## 2. 基线对比（无基线的模型不予采信）

- [ ] 至少一个朴素基线：时序用 naive（上期值）/季节 naive；回归用均值/中位数；分类用多数类；
- [ ] 复杂模型对基线的提升量级写进 RESULTS.md；提升 <1% 时诚实说明（并检查是否过拟合噪声）；
- [ ] 基线与主模型用**完全相同的评估协议**（同一切分、同一指标、同一数据预处理口径）。

## 3. 验证协议正确性

- [ ] 时序：滚动原点（Rolling/Expanding）或单次按时间切分，k 折随机 CV 已排除；
- [ ] 测试集只碰一次：禁止"试多个模型挑测试集最好的"（这是把测试集当验证集用，属泄漏）——模型选择在验证集/交叉验证内完成；
- [ ] 超参搜索与最终评估分离，记录搜索空间与选中超参（可复现）。

## 4. 区间/不确定性（题面要求区间预测时）

- [ ] 预测区间有构造依据（残差分位 / 分位数回归 / bootstrap），不是"点预测 ± 手拍的数"；
- [ ] 区间覆盖率在验证集上实测并报告（名义 95% 的区间实测覆盖率应接近，过低 = 区间失真）。

## 5. 数值与凭证

- [ ] 指标与题面对齐（回归：RMSE/MAE/MAPE 哪个是题目问的；分类：准确率在类不平衡时的误导性已评估，报告 F1/AUC）；
- [ ] 无 NaN 进模型（缺失处理策略已声明并一致执行）；类别变量编码一致（训练与预测同映射）；
- [ ] validate_capability() 断言通过（如：去泄漏后指标显著优于随机/naive、金标准来源已声明）；
- [ ] RESULTS.md 有 AUDIT_OK 凭证（无硬约束题按 n_constraints=0 口径）。

## 输出

`_tmp/problem_N_check.md` 逐条 ✅/⚠️/❌；❌ 修复后重跑本问全部脚本。

## 专项检查清单

```
P1. [过拟合] 训练集 vs 测试集精度差距是否异常？
   结合基线、样本量、指标不确定性与业务目标判断，不使用统一 10% 差距作为失败阈值
P2. [预测范围] 预测值是否在合理范围内？
   结合领域知识判断, 不是简单看历史极值
P3. [多步评估] 按预测步长报告误差与区间；有限样本下误差不必逐步单调增加
P4. [残差检验] 残差是否有明显的模式（自相关/异方差）？
P5. [验证方式] 验证方式是否合理？
   时间序列不能随机 split, 应该用滚动验证
P6. [拟合解释] 低 R² 或负测试集 R² 表示相对均值基线解释力有限，不自动等于程序错误。检查：
   - 模型形式是否正确？（是否遗漏基线漂移、非线性项、相位偏移）
   - 数据预处理是否正确？（去趋势、归一化、截取有效区间）
   - 初始参数是否合理？（非线性拟合对初值敏感）
   是否满足题目明确的精度要求、是否优于合适基线、误差是否影响下游决策。
   未达到真实交付标准时不能宣称适用；没有统一的 0.5/0.8 合格线，也不为提高 R² 改数据。
```

## 常见 Bug

```
M1. [线性假设] 用线性回归拟合明显非线性的数据？（看残差图是否有弯曲模式）
M2. [样本不平衡] 分类问题中各类样本量是否严重不平衡？是否用了 class_weight 或过采样？
M3. [特征缩放] SVM/KNN/神经网络等距离敏感模型是否做了特征缩放？
M4. [时序交叉验证] 时间序列是否用了普通 k-fold？（应该用 TimeSeriesSplit, 不能未来数据预测过去）
M5. [多重比较] 存在同一假设族的多次推断时说明控制方法（如 Holm/FDR/Bonferroni）及适用性；不强制对一切分析套同一校正。
```

## 红旗信号

| 现象 | 可能原因 |
|------|---------|
| R² > 0.99 但样本量 < 100 | 核对划分与基线；确定性映射也可能真实达到，不能仅凭高分判泄漏 |
| 训练 R² 高、测试 R² 低 | 过拟合 |
| 预测值超出历史数据范围 5 倍以上 | 模型外推发散/趋势项过强 |
| 远期预测单调发散（不收敛不震荡） | 模型不稳定/缺阻尼项 |
| 残差与预测值相关 | 模型欠拟合 / 非线性遗漏 |
| 残差自相关 | 漏了滞后项 / AR 结构 |
