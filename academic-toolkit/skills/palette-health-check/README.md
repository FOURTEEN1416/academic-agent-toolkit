# palette_kit_v6 —— 论文配色「去灰 / 提彩 / 可验证」工具包

> 来源：CUMCM 2026A 论文工程（`cumcm2026A`）第六轮配色优化。
> 定位：**可移植资产包**——把"用户 8 色板 → 印刷用色体系"的全部结论与机器可复核的工具抽出来，
> 供后续对 `academic-toolkit`（原仓库）升级、或其它论文工程直接复用。
> 本包**自包含**：不 import 论文工程的任何代码，仅依赖 `numpy` / `matplotlib`（画图板需要）。

## 一、这套工具解决什么问题

用户给了一组"看着比较不错、但几个颜色太深、发灰、不够鲜艳亮眼、有点克制"的 8 色板。
难点在于：**"发灰"是一句主观评价，必须翻译成客观可测量的量，否则改完还是靠眼缘。**

本包给出的量化口径：

| 概念 | 客观定义 | 判据 |
|---|---|---|
| **发灰（浑浊）** | `ratio = C* / C*max(L*, H°)`：该色在其明度/色相下**占 sRGB 色域上限的彩度比例** | 暖族应 ≥0.94；`ratio` 低 = 该位置本可更艳却没用满色域 = 发灰 |
| **深而浊** | 用 `darken(c,f)`（RGB 向黑等比缩放）压暗时，**彩度被同步砍掉** | 改用 `deepen(c)`：固定色相 H°、压 L*、彩度取色域上限的 `INK_RATIO` 倍 |
| **顺序色带单调** | 亮→暗色带在**灰度**下必须单调下降，否则出现"假亮带" | 累积回升 `max(L* − running_min(L*))` ≤ **0.5 L\***（**不能用逐样本差分**，会被稀释） |

一句话结论：**「发灰」的物理成因是彩度没用满该明度下的色域**；`darken()` 会雪上加霜，
`deepen()` 才是正解。

### 交叉复核的意义（方法论，勿省）

`palette_cvd_check_v6.py` **刻意重写了全部色彩数学**（Lab↔sRGB、Machado 2009 色盲矩阵、
CIE76 ΔE、L* 计算），不 import 论文工程里的 `gen_figures_v3.py`。
理由：若复核脚本与生成脚本共用同一份（可能有 bug 的）实现，就只能验证"自洽"，验证不了"正确"。
本次正是靠这份独立复核，抓到 v6 引入的一处**真实回归**（见下）。

## 四、踩过的坑（移植时必看）

1. **入带序 vs 排序序（本次抓到的真实回归）**
   只校验"按 L* 排序后的清单单调"是不够的——真正决定观感的是**色带按语义顺序入带时**的 L* 走向。
   v6 曾把 TMAIN 提亮到 L\*81.0，而 T2 仍 79.5，于是入带序 `T4→T3→T2→TMAIN→TACC` 在 T2→TMAIN 处
   **回升 1.55 L\***（灰度下即"假亮带"）。修复：T2 提到 L\*82.0。
   → `design_palette_v6.py` 已内置"入带序单调"校验；判据用**累积回升 ≤0.5 L\***。

2. **逐样本差分判单调会失灵**
   用相邻样本差分判断色带单调，会把"小回升"淹没在采样噪声里。必须用
   `max(L* − 运行最小值(L*))` 的累积口径。

3. **matplotlib 下标是独立 span，字号只有 0.7 倍**
   图内 `$T_\infty$` 这类 mathtext 下标会被渲染成**独立 text span**，
   导致该图的 10% 分位字号被拉到 5.2 pt（远低于其它图 7 pt 带）。
   图内标签**一律用纯中文名**，数学符号交给图题与正文。

4. **`darken()` 的诱惑**
   想压暗就 `c*f`，看着"深了"，其实彩度一起没了 → 浑浊。凡是要深色，用 `deepen()`。

## 五、移植到「academic-toolkit」的接法（建议）

原仓库已有三道图件闸（`_utils/tikz_palette_check.py`、`figure_text_budget.py`、
`figure_pdf_quality_check.py`）。本包建议补第四道 **色彩健康闸**，接口对齐既有闸：

- 输入：论文的色板定义（JSON 或脚本常量）。
- 输出：PASS / FAIL + `ratio` 低于阈值的色、墨色对比度不足的色、色带累积回升超限的带。
- 判据：`ratio_floor`（暖/冷族可分别设）、`ink_contrast ≥ 4.5`、`cum_rise ≤ 0.5 L*`。
- 复用：本包的 `palette_cvd_check_v6.py` 已具备全部量测，转成闸只需加一个 argparse 与退出码。

## 六、结论一句话

配色不是美学玄学：**「发灰」= 彩度未用满色域**，可用 `C*/Cmax` 量测；
**「深而浊」= 用了向黑缩放的 `darken`**，应换成固定色相的 `deepen`；
**「假亮带」= 色带灰度非单调**，用累积回升量测且必须按**入带序**校验。
本包把这三条做成了可跑、可复核、可移植的工具。
