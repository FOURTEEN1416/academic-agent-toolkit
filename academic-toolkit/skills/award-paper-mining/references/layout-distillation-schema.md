# 版面蒸馏作业标准（layout-distillation-schema）

> 本文是 `award-paper-mining` 执行步骤 6（版面蒸馏）的唯一作业标准。
> 目标：在作者已有自己的建模、数据与计算结果的前提下，把成果套上国奖水准的论文外壳。
> **只还原版面层**；模型推导、代码实现、方案决策一律不抽。

## 一、版面层五类资产（抽什么）

| # | 资产 | 定义 | 落点 |
|---|------|------|------|
| 1 | 章节骨架 | 摘要页内部槽位结构 + 正文章节树（层级/顺序/每章功能/小节数） | 版面卡 |
| 2 | 摘要页结构 | 国奖摘要的黄金槽位序列与字数区间 | 版面卡 + 聚合库 |
| 3 | 段落功能句式 | 各章典型句式的**带槽位抽象模板**（开头/承接/结果陈述/假设陈述等） | 版面卡 + 聚合库 |
| 4 | 图表规范 | 图表类型×使用场景映射、图题表题格式、密度、三线表样式、配色风格 | 版面卡 + 聚合库 |
| 5 | 排版规格 | 字体字号层级、行距、公式编号格式、页眉页脚、页数区间 | 版面卡 + 聚合库 |

**排除项（不抽不写）**：模型公式推导链、算法伪代码、代码实现、参数取值的合理性论证、
方案选择理由。版面卡中与这些相关的字段一律不设。

## 二、读取路线决策

1. 优先用**仓内页面件**（`assets-local/award-papers/<年>/<论文号>/*.jpg`，唯一真源）做视觉读取；
   归档合并件 `年_论文号.pdf` 仅作快读对照。
2. 逐篇先探测文本层：合并件能用文本抽取（pdftotext/pdfplumber 等）抽通则文本走文本层，
   版面属性（图表样式/排版）仍走视觉；抽不通（扫描件）则全文视觉读取，**如实登记
   `text_layer: "no"`，不伪造文本**。
3. 单页视觉读取一次拿到该页的：章节标题及层级、图表存在性与样式、排版特征、典型句式。

## 三、版面卡 schema（每篇一个 JSON）

落点：`assets-local/award-papers/layout-distill/<年>_<论文号>.json`

```json
{
  "paper_id": "2021_A217",
  "source": {"pages_dir": "assets-local/award-papers/2021/A217/", "text_layer": "yes|no|partial"},
  "pages_total": 23,
  "page_count_within_range": true,
  "abstract": {
    "page": 1,
    "slots": ["问题背景一句", "针对…问题，建立…模型", "方法链", "关键结果数字", "关键词"],
    "word_count_range": "800-1000（页面级目测口径）"
  },
  "section_tree": [
    {"title": "问题重述", "level": 1, "page": 2, "subsections": 0, "function": "背景+问题拆解"},
    {"title": "模型假设", "level": 1, "page": 3, "subsections": 0, "function": "假设编号+依据"}
  ],
  "standard_sections": {
    "摘要": true, "问题重述": true, "问题分析": true, "模型假设": true,
    "符号说明": true, "模型建立": true, "模型求解": true,
    "模型检验/灵敏度": false, "模型评价": true, "参考文献": true, "附录": true
  },
  "figures_tables": {
    "figures": 12, "tables": 8,
    "fig_caption_format": "图3-1 xxx（章节号.序号）",
    "table_caption_format": "表2-1 xxx，三线表",
    "per_page_density": "0.9（图表数/正文页数）",
    "type_usage": {"流程图": "建模思路页", "曲线图": "结果对比页", "热力图": "灵敏度页"}
  },
  "typography": {
    "heading_levels": "一级黑体三号/二级黑体四号（目测口径）",
    "body_font": "宋体小四，1.5倍行距（目测口径）",
    "equation_numbering": "(3-1) 章内编号",
    "header_footer": "页眉无/页脚页码居中"
  },
  "sentence_patterns": [
    {"chapter": "模型假设", "slot_template": "考虑到{实际背景}，本文假设{假设内容}（依据：{来源}）", "seen_pages": [3]}
  ],
  "notes": "缺页/模糊页/不可判定字段如实登记"
}
```

规则：目测型字段（字体/字号/行距）标 `（目测口径）`；不可判定标 `unavailable`；
每条统计在聚合时带样本量。

## 四、聚合规范库（四个，落技能 `data/`，摘编入 git）

| 文件 | 内容 | 抽象要求 |
|------|------|---------|
| `data/abstract_golden_structure.md` | 摘要黄金槽位序列（跨篇出现率排序）+ 各槽位句式模板 | 模板带槽位，附出现率与样本量 |
| `data/sentence_pattern_library.md` | 按章节组织的句式模板库 | 只收跨 ≥2 篇出现的模式；槽位化 |
| `data/figure_table_conventions.md` | 图表规范（题注格式/三线表/类型×场景/配色风格归纳） | 与 fig-aesthetics-craft 口径兼容 |
| `data/typography_spec.md` | 排版规格汇总 + 与 `docx`/LaTeX 模板参数的映射建议 | 给参数化建议，不绑定具体模板 |

每个文件文首必须有**口径声明**：样本量（N 篇）、覆盖年份、"出现率"定义。跨篇出现率 <40%
的模式标 `低频，慎用`。

## 五、分批与断点续作

- 批次按年：批1=2021(17) → 批2=2022+2023(22) → 批3=2024(16) → 批4=2025(7)+聚合收口。
  单窗口建议一批；完成后更新 `layout-distill/progress.json`（done/failed/待办清单+时间戳）。
- 断点续作：新窗口先读 `progress.json`，只补差，不重跑已完成篇。
- 每批结束跑一次聚合增补（规范库是累加式，不整库重写）。

## 六、红线（违反即返工）

1. 入 git 的句式/段落只能是**带槽位抽象模板**或跨篇归纳规范；成段原文、整页仿写不得入 git。
2. 套壳使用时，正文内容必须全部来自用户自有建模、数据与结果——外壳参照 ≠ 内容搬运。
3. 版面卡字段缺失标 `unavailable`；扫描件标注视觉读取路线；不可核验的数字不写。
4. 版面资产落私有区（`layout-distill/`），git 只进四个规范库与本 schema 的执行差异记录
   （如有，进 LOG 不进正文）。
