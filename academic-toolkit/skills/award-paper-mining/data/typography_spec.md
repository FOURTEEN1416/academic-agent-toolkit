# 排版规格（typography_spec）

> **口径声明**：样本量 N=9 篇（2021 年国奖）。目测型字段（字体/字号/行距）均标`（目测口径）`，
> 不可核验的数字不写。**出现率定义**：符合该规格的篇数 ÷ 可观察样本数（排版可观察 N=8，
> C085 仅部分页）。版本：v1（2026-09-23 批1 首建，后续批次累加式增补）。

## 一、页面与页眉页脚（高置信）

| 规格 | 出现率 |
|------|--------|
| 无页眉 | 8/8 |
| 页脚页码居中、阿拉伯数字 | 8/8 |
| 页码自摘要页起算第 1 页（无独立封面页） | 7/7 可核验 |
| 纸张 A4、单栏 | 8/8 |

## 二、字体层级（目测口径）

| 层级 | 规格 | 出现率 |
|------|------|--------|
| 论文标题 | 黑体/加粗大号，居中，摘要页顶部 | 8/8 |
| 章标题 | 黑体三号左右，居中，「中文数字、标题」 | 8/8 |
| 节标题 | 黑体四号左右，左对齐，「x.y 标题」 | 8/8 |
| 小节标题 | 黑体小四-四号，左对齐，「x.y.z」 | 8/8 |
| 四级标题 | 「x.y.z.w」（A028）或「1）」括号编号（A115/A028） | 2/8 `低频，慎用` |
| 正文 | 宋体小四 | 8/8 |
| 强调 | 关键结论/模型名加粗（摘要与正文） | 4/8 |
| 章题号分隔 | 顿号「一、」为主流 7/8；句点「一.」1/8 | |

## 三、段落与行距（目测口径）

| 规格 | 出现率 |
|------|--------|
| 首行缩进 2 字符、两端对齐 | 8/8 |
| 行距约 1.5 倍 | 7/8（D034 视觉更疏，约 1.5-2 倍） |

## 四、公式排版

| 规格 | 出现率 |
|------|--------|

## 五、章节骨架模板（国奖外壳默认版）

```
摘要（独立1页：标题+摘要+关键词）
一、问题重述（1.1 背景 / 1.2 提出或已知条件）
二、问题分析（逐问一节或行内标签）
三、模型假设（编号 3-6 条）
四、符号说明（三线表：符号/说明/单位）
五、模型建立与求解（每问一节：准备→建立→求解→结果分析）
六、模型评价（与推广）（优点/缺点/改进/推广）
七、参考文献（GB/T 7714，[J][D][M]）
附录（代码/完整表，编号+说明）
```

- 章序变体：符号说明在模型假设之前（D026/A028，2/8 `低频，慎用`）。
- 章名变体：「算法假设/算法建立与求解/算法评价与推广」算法流派（D034，1/8 `低频，慎用`）。
- 独立检验章：敏感度分析/模型优化独立成章置于评价之前（A115/D026，2/8）。
- 无参考文献直接进附录（D017，1/8 `低频，慎用`，不建议模仿）。

## 六、与模板参数的映射建议（参数化建议，不绑定具体模板）

| 版面要素 | LaTeX 映射建议 | docx 映射建议 |
|----------|---------------|---------------|
| 章标题 | `\section{}` + ctexset 黑体居中 | 标题1：黑体三号居中 |
| 节标题 | `\subsection{}` 黑体左对齐 | 标题2：黑体四号左对齐 |
| 正文 | 宋体映射（ctex 默认），小四 12pt，1.5 倍行距 | 正文样式：宋体小四 1.5 倍 |
| 公式编号 | 全文连续：`\numberwithin{equation}{}` 置空 + `\tag` 或手动 | 题注/编号域手动 |
| 三线表 | booktabs（\toprule/\midrule/\bottomrule） | 三线表样式（上下粗 1.5pt、栏目线 0.75pt） |
| 页码 | `\pagestyle{plain}` 页脚居中 | 页脚居中页码域，首页起算 |
| 附录代码 | listings/minted 灰底盒 | 等宽字体+底纹段落样式 |
