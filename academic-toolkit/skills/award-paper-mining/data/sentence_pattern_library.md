# 句式模板库（sentence_pattern_library）

> **口径声明**：样本量 N=9 篇（2021 年国奖：A028/A115/B026/B160/C085/D017/D026/D034/E037），
> C085 为部分样本（缺前段，仅贡献模型建立/求解/参考文献章证据）。覆盖年份 2021（批1）。
> **出现率定义**：跨篇出现该模式的篇数 ÷ 可观察样本数（按章标注，8 或 9）。
> 收录标准：仅收跨 ≥2 篇出现的模式；单一篇独有的标 `低频，慎用`。全部为带槽位抽象模板。

## 一、问题重述章

| 模式 | 模板 | 出现率 |
|------|------|--------|
| 背景引入 | `{对象}是{过程描述}，而{关键技术}是{对象}的关键技术之一，直接影响了{指标A}和{指标B}。` | 4/9 |
| 逐问枚举 | `问题{k}：在{前提}下，{任务描述}，按照"{交付字段}"等内容列表给出{交付物}。` | 6/9 |
| 名词解释表开场 | 表1 罗列`{术语}/{释义}`后再述问题（无小节平铺流派） | 2/9 |
