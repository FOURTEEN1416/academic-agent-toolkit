# 图表规范（figure_table_conventions）

> **口径声明**：样本量 N=9 篇（2021 年国奖，题型 A×2/B×2/C×1 部分/D×3/E×1）。
> **出现率定义**：采用该规范的篇数 ÷ 可观察样本数（图表可观察 N=9，C085 按抽样页计）。
> 与 `fig-aesthetics-craft` 口径兼容：本库只记版面规范，不记配色审美。
> 版本：v1（2026-09-23 批1 首建，后续批次累加式增补）。

## 一、题注规则（高置信，出现率 ≥89%）

| 规范 | 出现率 | 说明 |
|------|--------|------|
| 表题注在表**上方**、图题注在图**下方** | 9/9 | 全样本一致 |
| 题注加粗/黑体、居中 | 9/9 | |
| 图表全文连续阿拉伯编号（图N/表N，无章节前缀） | 7/9 | 例外见下 |
| 编号格式变体：`表N：xxx` 冒号式 | 2/9 `低频，慎用` | D026/C085 |
| 中文数字图题 `图一：xxx` | 1/9 `低频，慎用` | A028 |
| 子图双层题注：`图N(a) 小题注` + 总题注 | 2/9 | B160/A115 |
| 双行题注（正题+括号补充行） | 1/9 `低频，慎用` | A115 |

## 四、密度与分布（页面级目测口径）

- 图表层/正文页 ≈ 0.4-2.0：D 型结果表密集可达 2.0（表驱动型），A 型推导型可低至 0.4（公式驱动型）。
- 大数据结果表倾向「部分展示+附件外置」而非全量排印（2/9）。

## 五、配色风格归纳（页面级观察）

- 统计图以软件默认色为主（Excel 蓝橙灰、matplotlib tab10、MATLAB 蓝）；分类着色语义化（红/绿/蓝对应 A/B/C 类）出现 2/9。
- 正文无装饰性配色；水印为展示源所加非论文本身。

## 六、研赛（华为杯）图表惯例增量（2026-10-01，W2-CORPUS 批）

> **口径声明**：新增样本=研赛语料 686 篇（2004-2025）；本节机读子样本 N=60（2011-2025 官方编号件随机抽样）。
> **出现率定义 A（题注格式）**：文本层正则"出现次数"口径（含正文对图表的引用，非纯题注行），
> 故为倾向性指标而非精确题注统计；格式占比=该格式出现次数 ÷ 三类格式总出现次数。
> **出现率定义 B（目录页/路线图）**：篇级存在性口径（60 篇中具备该特征的篇数）。
> **目验**：3 篇渲染样张（2018_D18106110053 目录页 / 2023_C23102540029 全页路线图 / 2018_D18116460078 图组页）。
> **排除**：contest_evidence=no 的 150 篇不参与本节归纳。
> 图表密度机读口径（686 篇全量）：图题注中位 13、表题注中位 10（行首正则口径，低于真实总数）。

### 6.1 题注编号制（与国赛的跨赛事差异，高置信）

| 规范 | 文本出现占比 | 说明 |
|------|------|------|
| 章内编号「图N-N / 表N-N」（章号-序号） | 图 1466/2695≈54%；表 622/1190≈52% | 研赛主流制；国赛 2022 批 10 篇主流为全文连续制（8/10），两赛事**不同流** |
| 全文连续「图N」 | 图 1204/2695≈45%；表 518/1190≈44% | 并存流派 |
| 冒号式「图N：」 | 图 35≈1%；表 50≈4% | `低频，慎用` |
| 子图题注「(a) 小题注 + 总题注」 | 目验 2/3 样张 | 与国赛同构 |
| 表题注上、图题注下 | 目验 3/3 | 与国赛一致 |

### 6.3 使用建议（带槽位，供 comp-paper-zh 研赛链引用）

- 研赛链题注采用「图{章号}-{序号} {题注}」制；章前给目录页；问题群复杂（≥4 问）时给一张全页泳道式技术路线图，每问一条横向泳道，算法与评价指标以虚线框分组。
