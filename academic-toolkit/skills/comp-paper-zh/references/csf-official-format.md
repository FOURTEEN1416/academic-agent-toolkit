| 件 | 必要性 | 格式 | 命名（题号+队伍号+后缀） |

| 承诺书 | **必要** | PDF / JPG / PNG | `ACSF2600001cns.pdf`（或 `.jpg`/`.png`） |

- **题号**取赛道字母（`A`/`B`/`C`）+ 赛事代号 `CSF` + 年份 `26` + 队伍号；示例中的数字段是队伍号、非固定值。

## 二、论文页序（硬）

1. **摘要（summary）必须是论文文件的第一页**，**不能分为两个文件**；
2. 正文；
3. **源程序作为附录放在正文之后，与正文编辑在同一个文件中**；
4. 源程序**同时**要放进支撑材料。

> 即：论文是「摘要页 → 正文 → 代码附录」**同一个 PDF**；不存在单独的代码文件参展。

## 三、仿真视频规格（硬）

| 项 | 规定 |
|---|---|
| 容器 | **MP4** |
| 时长 | **原则上 ≤ 3 分钟**；建议**前 30 秒**介绍作品概况，其余展示核心与亮点 |
| 分辨率 | **≥ 1280×720** |
| 大小 | 建议 **≤ 300 MB** |
| 必须包含 | ①**模型界面与功能模块介绍**；②**运行过程演示**（屏幕录制或软件内录屏，关键参数/节点可特写）；③**结果分析与可视化**（结果、数据分析过程、重要图表曲线） |

## 四、匿名与原创性

- **任何提交材料不得出现可能透露参赛队伍个人信息的内容（如姓名、学校）**。
  - ⚠️ 承诺书本身需队员签名，属规则明确豁免的独立件，不与匿名要求冲突。
- **不允许跨校组队、不可重复组队**；每队 1–3 名学生 + 1 名指导教师。
- **指导教师不得直接参与**赛题求解、模型构建、代码编写、论文撰写（章程第十条）。
- 论文格式须符合《全国大学生仿真建模应用挑战赛**论文规范**》，**不符合规范的论文不予参评**。
- 组委会对全部提交论文做**原创性审查**；不得侵犯他人知识产权。
- **2025 首届**条款（非当届）：全文疑似 AIGC 生成比例 > 30% 或全文总相似比 > 50% → 雷同论文 → **取消评奖资格**。当届未取证，按「可能沿用」谨慎对待，**不作为机读阈值**。
