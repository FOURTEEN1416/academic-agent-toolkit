# CSF 论文骨架 — 使用说明

- **赛事**：全国大学生仿真建模应用挑战赛（中国仿真学会 CSF + 吉林财经大学），2026 为第二届。
- **基底**：由 `_templates/default/main.tex`（ctexart 通用中文论文骨架）派生。
- **本目录用途**：`comp-paper-zh` 的 CSF 分支装载骨架；机读真源是
  `engine/modex-core/comp_rules.json → contests.comp_csf`。

## 硬约束（已取证，逐条已写入 main.tex 头注）

| 项 | 要求 |
|---|---|
| 文件 | 仅 **PDF**、**不压缩**、只交 **1 个**文件；命名「题号+队伍号+pdf」（例 `ACSF2600001.pdf`） |
| 摘要 | 必须是**论文文件第一页**，不能拆成两个文件 |
| 代码 | 源程序作**附录**放正文之后，**与正文同一个文件**；同时另放入支撑材料 |
| 承诺书 | **独立件**，绝不能并入论文文件 |
| 匿名 | 任何页面不得出现姓名/学校等身份信息 |

## ⚠️ 未确证项（保持模板默认，不作官方主张）

官方《全国大学生仿真建模应用挑战赛**论文规范**》（章程第十条指向的唯一格式真源）截至 2026-10-16
**未公开直读**——以下项目**全部缺席**，禁止臆测：

- 页数上限（正文/总量）
- 页边距、字体字号、行距
- 页眉页脚、页码位置与起始
- 摘要页要素（关键词/英文/页数限制）
- 参考文献体例、是否要求目录页

本骨架因此采用**保守默认**：A4、四边 2.5cm、摘要独占首页、不出目录、页脚居中页码、无身份信息。

**取得正式件后必须：**
1. 回填 `engine/modex-core/comp_rules.json → contests.comp_csf` 对应约束；
2. 更新 `skills/comp-paper-zh/references/csf-official-format.md` 的「缺口」节；
3. 复核并同步本目录 `main.tex`。

> 相关工具：四件套提交打包校验见 `academic-toolkit/tools/pack_csf_submission.py`；
> 仿真方法与产物契约见技能 `comp-simulation`。
