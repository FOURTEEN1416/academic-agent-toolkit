# 七项做法 × 国赛优秀论文验证对照参考件（范例对照评审用）

> **定位（学术工具箱口径）**：本参考件把「对照优秀论文范例」这一评审维度落地为可操作清单。
> 适用域**以全学术论文为第一口径**（任何"主张-证据-比较"型学术文本皆可套用），数模竞赛论文
> 为**已完成验证的落地场**。通用入口是 `skills/oral-paper-skill/`（上游 Adkid-Zephyr/oral-paper-skill，
> 883 篇 ICLR/ICML/NeurIPS Oral 摘要蒸馏；借鉴使用、出处保留）；本件是其七项做法经本地
> 优秀论文实证验证后的**本土化对照层**。
>
> **与既有统计报告的关系**：`assets-local/award-papers/参考论文使用指南.md`（62 篇 2021-2025 国赛优秀论文）
> 给的是"形"的统计规律（摘要 700-900 字、四要素齐全、≥3 个数值结果、背景导入式开头 91.9%）；
> 本件给的是"核"的语义做法（七项做法迁移成立度）。两边互补，不互替。

## 验证方法与样本（2026-09-23 轻量试点批）

精读 10 篇 2023-2025 国赛优秀论文**摘要页**（本地语料 `assets-local/award-papers/`），逐篇核对七项做法的
出现形态与成立度。样本：2025-A196(A)/C023(C)/E030(E)、2024-A016(A)/B159(B)/C094(C)/E010(E)、
2023-A0127(A)/B477(B)/D039(D)，覆盖 A 机理优化 / B 离散与几何 / C 统计大数据 / D 运筹规划 /
E 交通环境五类。**方法限定**：轻量试点（LOG 续53 裁决），非统计口径；成立度仅代表样本内
趋势，不外推为全体优秀论文规律。以下引证以转述+极短引语为主，编号指代语料原文。

## 七项做法逐条验证

### 1. 写清研究张力 —— **条件成立**（分问题类型）

| | |
|---|---|
| 通用定义 | 用具体限制/矛盾现象说明问题为什么值得研究，不造前人失败 |
| 数模形态 | "方案设计/策略优化"类强出现；"求解计算"类允许背景导入替代 |
| 实例 | 2023-B477 开篇即具体缺口："不能简单地根据海区平均水深设计测线间隔"；2023-D039 由"不同阶段羊只对空间要求不同→利用率矛盾"引入；2025-C023 以"准确性高度依赖 DNA 浓度，浓度受孕周/BMI 显著影响"定张力 |
| 例外（与上游一致） | 2024-A016 求解型直接从螺线方程出发，张力薄仍是优秀论文——不硬造张力 |
| 评审要点 | 策略/设计类摘要只有"随着…具有重要意义"而无具体矛盾或未满足要求时，提示补一句"具体缺口" |

### 2. 明确贡献增量 —— **强成立（10/10）**，数模本土形态

| | |
|---|---|
| 通用定义 | 去掉方法名和"novel"仍能说清改变了什么 |
| 数模形态 | **方法组合 delta + 策略 delta**（非顶会的"改假设/改表示"） |
| 实例 | 2025-A196"引入布尔函数判断遮蔽有效性，表达更简洁易懂"；2025-C023"混合效应模型与风险最小优化模型相结合的框架"；2023-A0127"分区域同心圆规划策略" |
| 评审要点 | 摘要通篇是方法名堆叠（"用了 X、Y、Z"）而说不出组合/改进了什么时，提示补 delta 句 |

### 3. 让证据对应主张 —— **强成立（10/10）**，数值密度极高

| | |
|---|---|
| 通用定义 | 每个主张对应实际测到的属性；代理/假设/结果分明 |
| 数模形态 | 主结果**精确复现值**+**验证手段**并列（对应既有统计"≥3 个数值结果"） |
| 实例 | 2025-A196 遮蔽时长精确到 1.391643s 且给"粒子群 vs 蒙特卡洛相对误差 0.01%"算法对照；2025-C023 R²=0.8962；2024-B159 最优期望利润 56.7/54.2 元分问给数 |
| 天花板形态 | 2024-C094 **双口径并列+差异归因**：同一问"滞销口径 40244799.20 元 / 折算口径 56328297.78 元"并解释差异来源（降价后高收益作物仍被高频种植） |
| 评审要点 | "误差较小/效果良好/性能优异"式无支撑形容→提示替换为数值；主张-指标错位（声称鲁棒却只给均值）→提示补扰动实验数字 |

### 4. 选择有解释力的比较 —— **强成立（10/10）**，三种形态

| | |
|---|---|
| 形态① 多方法择优 | 2024-E010 K-means/DBSCAN/GMM 三聚类对比选时段划分；2024-C094"求解器 vs 贪心：各有优缺点，根据具体需求选择"（比较回答了"选哪个"的决策） |
| 形态② 与基准对比 | 2025-C023 拟合优度"显著优于传统广义线性模型"（基准明确） |
| 形态③ 跨问/跨情形对照 | 2024-C094 问题三结果"相较于第二问更优，符合优化目标"；2024-E010 问题四对管控前后数据"对比分析，量化管控措施的效果" |
| 灵敏度/鲁棒子形态 | 2024-C094 蒙特卡洛 100 组扰动选"抗扰动性最强"方案（均值 51667432.02 元）；2024-B159"超参数选取对利润期望影响较小"一句话收尾 |
| 评审要点 | 比较不说明"回答什么决策、控制了什么"（如不同数据量/参数下比）→提示；只报自己方法结果无任何对照→提示补 |

### 5. 条件紧随结论 —— **成立**（载体=模型假设+参数条件+约束区间）

| | |
|---|---|
| 数模形态 | 模型假设章是此做法的结构化载体；摘要层面表现为显式假设句+参数条件+区间结论 |
| 实例 | 2024-E010 显式假设"车流平均速度与绿灯时长/周期时长比值成正比"；2023-A0127 结果紧带参数条件"镜尺寸 5.5×5.5、安装高度 2.75m、共 3385 面"；2023-D039 区间结论"年化出栏估计 1163 至 1312，达 1500 缺口约 16 至 32" |
| 高分形态 | **模型简化决策明示**：2023-D039"非线性约束非常多，基本不可解，我们对模型进行了简化，固定间隔和数量"——把简化作为决策交代而非掩盖 |
| 评审要点 | 结论无适用条件/参数口径（哪个情形、哪组参数、什么约束下）→提示补；私自简化模型不明示→提示交代 |

### 6. 说明资源支持的研究 —— **形态特化成立**

| | |
|---|---|
| 数模形态 | 非"开源数据集"式，而是**结果文件逐问交付 + 附录索引 + 交付物说明** |
| 实例 | 2024-A016 每问"将结果存入 result1.xlsx，展示部分结果在表 1 和表 2"（四个 result 文件逐一交付）；2023-A0127"具体求解结果见附录二/三/四"；2025-C023 交付交互网页 |
| 评审要点 | 问题要求交付结果文件而摘要未提交付→提示核对 submission checklist；附录结果与正文数值口径不一致→交叉核对 |

### 7. 提炼有边界的认识 —— **弱成立（摘要层面 3/10 显性）**，最大差异点

| | |
|---|---|
| 通用定义 | 读者能带走什么、何时不适用；观察/解释/行动分开 |
| 数模现实 | 摘要页让位于数值结果，边界认识主要落在**正文"结论与推广"章**；摘要内仅偶见（2023-B477"对实际海底地形测绘有一定参考价值"——有边界的措辞；2025-C023 稳健性与实用性验证声明） |
| 评审要点 | **摘要层面不强求本做法**（避免把数模摘要改成顶会腔）；转正文检查"模型评价与推广"是否交代适用范围与局限 |

## 权重反转表：顶会 abstract vs 数模摘要页

| 做法 | 顶会 | 数模摘要页 | 说明 |
|------|------|-----------|------|
| 1 研究张力 | 强 | 中（分题型） | 方案设计类强，求解类可背景导入 |
| 2 贡献增量 | 强 | 强（本土形态） | 方法组合/策略 delta |
| 3 证据对应主张 | 强 | **更强** | 数值密度极高，精确复现值+验证 |
| 4 有解释力比较 | 中强 | 强 | 多方法择优是数模特色 |
| 5 条件紧随结论 | 强 | 中 | 由假设章承接 |
| 6 资源说明 | 视类型 | 特化 | 结果文件/附录交付 |
| 7 有边界认识 | 强 | **弱** | 让位数值结果，正文承接 |

## 高分加分形态清单（评审时逐条对照）

1. **双口径并列+归因**（2024-C094 式）：同一结果两种口径并列并解释差异来源；
2. **算法对照验证**（2025-A196 式）：主算法与独立方法（蒙特卡洛等）对照给误差百分比；
3. **模型简化明示**（2023-D039 式）：把"为何简化、简化了什么"作为决策交代；
4. **灵敏度一句话收尾**（2024-B159 式）：关键参数扰动对结论影响的一句话定量陈述；
5. **具体张力第二句嵌入**（2023-B477 式）：背景导入句后紧跟具体缺口句，而非通篇宏观意义。

## 使用方式与边界

- **加载时机**：comp-review Step 2（逐条对撞五类缺口）按需加载本件；产出仍走 comp-review 既定裁定格式；对稿件提范例对照建议时**默认 ≤3 条**（沿上游 oral-paper-skill 纪律），每条注明"哪项做法+语料对应形态+稿件现状+具体改法"。
- **边界声明**：本件样本为 10 篇摘要页轻量试点，成立度是样本内趋势而非统计规律；做法体系出处为上游 oral-paper-skill（借鉴使用），本地验证材料为私有获奖论文语料（`assets-local/award-papers/`，gitignored，引证均为转述）。
- **候选机检项（未实现，不扩权）**：做法 3/4 可部分机检——泛化形容词表（"误差较小/效果良好"）、比较句检测（"优于/相比/相较于"）——仅登记候选，待独立批次裁决。
