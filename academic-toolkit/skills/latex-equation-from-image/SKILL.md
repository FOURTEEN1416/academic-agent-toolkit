# 公式图片 → LaTeX 转写（带数值自检）

## 概述与边界

把**图片/截图里的公式或表格**变成可编辑 LaTeX：视觉转写（驱动侧视觉模型负责）→ LaTeX 规范化 → sympy 数值自检（本技能脚本）→ 带**置信度标记**交付。

与同域技能分工：

- `plot-from-image`：整图配色/字体/版式复现——那不是本技能的事；本技能只转写公式与表格的**内容**。
- `sympy-verify-math`：对既有推导做逐符号验证——本技能转写完的片段可交给它做进一步符号处理，但转写自检用本技能自带脚本即可。
- 题面文字理解、建模口径分析：回到对应领域技能；本技能不做题。

## 输入 / 输出契约

**输入**：含公式或表格的图片/截图（PNG/JPG/SVG，截图需清晰、无严重斜切）；可选：已知变量值（用于自检）、公式上下文（正文语义，帮助消歧 `l`/`1`、`O`/`0`、上标层次）。

**输出**：

1. LaTeX 片段（公式用行内/行间语法；表格用 `tabular`）；
2. 数值自检记录（命令 + 输出）；
3. 置信度标记：`high` / `medium` / `needs-review`。

## 工作流

1. **视觉转写**：由具备视觉能力的驱动侧模型读图转写；逐符号注意大小写、上下标层次、希腊字母与运算符。驱动侧**无视觉能力时如实说明并停止**，不要凭空编造转写结果。
2. **LaTeX 规范化**：`\frac{}{}`、上下标花括号补全、`\sqrt`、希腊字母命令、表格 `tabular` 列对齐；把 ±、≤、∈ 等符号还原为标准命令（`\pm`、`\le`、`\in`）。
3. **数值自检**（`scripts/verify_latex.py`，sympy 实现）：
   - `eval` 模式：把转写式在已知赋值下求值，与独立计算的参考值对账；
   - `check` 模式：两个等价形态的转写（如"分式原样" vs "展开式"）在随机采样点上比对；
   - 根/解类公式：求值后**回代**原方程，残差应为 0。
   - 表格：对可计算的列（合计、差值、均值）做勾稽。
4. **标注置信度**（判据见下表），连同 LaTeX 片段与自检记录一起交付。
5. **交付**：默认交付到一个 markdown 文件（公式块 + 自检命令与输出 + 置信度），便于人工复核。

## 置信度判据

| 标记 | 判据 |
|---|---|
| `high` | 自检全过（回代残差 0 或多采样点一致）且符号无歧义（无 l/1、O/0 类混淆） |
| `medium` | 自检通过但存在易混符号、或图片分辨率/裁切影响个别字符；建议人工复核 |
| `needs-review` | 自检不过、无法自检（纯符号式无已知赋值）、或驱动侧视觉能力缺席；必须人工读图确认 |

## 表格转写

表格按 `tabular` 转写：列头原样保留，数值列保留原始精度（不四舍五入）；对含合计/差值/均值关系的列做勾稽自检（如 `15.1 - 12.4 = 2.7`）。图片表格的数字转写天然易错，除非自检勾稽全过，否则一律标 `medium` 及以下。

## 验证命令示例

```bash
# eval：已知赋值求值（与独立参考值对账）
python scripts/verify_latex.py eval --expr "(-b + \sqrt{b^2 - 4ac})/(2a)" --assign a=2 b=3 c=-5

# check：两个等价转写在采样点比对
python scripts/verify_latex.py check --lhs "1/(\sigma \sqrt{2\pi}) e^{-(x-\mu)^2/(2\sigma^2)}" \
    --rhs "e^{-x^2/2}/\sqrt{2\pi}" --assign mu=0 sigma=1 --samples 8
```

> 路径相对本技能目录。表达式容忍常见 LaTeX 残留（`\frac{}{}`、`\sqrt{}`、`\pi` 等希腊字母、隐式乘法 `4ac`/`2a`、`e^` 按欧拉常数处理）；完整规则见脚本 docstring。

## 退出判据（Verification）

- [ ] LaTeX 片段可被 sympy/编译器接受（无语法错误）；
- [ ] 数值自检已执行且留有命令与输出；自检不过时标 `needs-review`，不得静默交付；
- [ ] 置信度标记按判据表给出，不虚标 `high`；
- [ ] 交付件含"待人工复核项"清单（若有）。

## 常见合理化（Common Rationalizations）

- "图很清楚，不用自检了" → 视觉转写的错误恰好在"看起来清楚"的图上发生（l/1、上标层级）；自检是本技能的硬闸，跳过即未完成。
- "自检没过，但大概是对的，先标 high" → 自检不过是 `needs-review` 的直接判据，虚标置信度比转写错误更严重。
- "没有已知变量值，没法自检" → 如实标 `needs-review` 并给出可自检的特例建议（如令参数取 1）；而不是跳过置信度标记。
