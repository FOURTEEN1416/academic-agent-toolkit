## 模式一：超宽画布多指标面板

**何时用**：一张图并排比较 3~4 个指标 × 多个方法（竞赛论文"多指标对比总图"最常见的翻车场景——纵向挤成一团）。

```python
fig, axes = plt.subplots(1, 4, figsize=(28, 6))   # 宽高比 3~4 : 1
```

**📏 期刊栏宽锚点（2026-09-11 收编自 fig-academic @`1df9940`，Apache-2.0）**：单栏 **89mm**（3.5in）、双栏 **183mm**（7.2in）是 Nature 系/CNS 通用口径，也是"最终印刷宽度"的权威取值来源——1×4 连排在 183mm 双栏下每格仅 ~43mm<45mm，按前置条件应改 2×2。竞赛论文（单栏版心 ~150mm）同理先量后连排。

**⛔ 印刷宽度前置条件（2026-09-10 增，先于上式判断）**：上游 (28,6) 级画布是屏幕/海报审图口径，直接缩进版面会翻车——28 in 缩到双栏 ~170mm 后每格仅 ~40mm、单栏 85mm 更窄，字号必跌破 7-9pt 可读下限。**仅当"最终印刷宽度 ÷ 面板数 ≥ 45mm"时才用 1×N 连排**；不满足就改 2×2 或 1×2 堆叠（本技能 SKILL.md 既有守卫"每 panel ≥ 0.45\textwidth"是同一约束的 LaTeX 侧表达）。竞赛论文（单栏版心）实际很少满足 45mm/格，连排前先算这一步。

**为什么**：读者从左到右扫读指标叙事，y 轴与图例保持可读；纵向拥挤是审稿人"看不清"吐槽的头号来源。子图间字号/线宽/语义色必须一致（一致性优先于逐轴装饰）。

## 模式二：独立图例面板

**何时用**：曲线/分组多到图例会压住数据区时。本库 `figure_check.sh` 与 vision 质检都会抓"图例压数据"，此模式是根治手法。

```python
ax_leg = fig.add_subplot(grid_spec[-1])   # 网格中专门留一格
ax_leg.set_axis_off()
ax_leg.legend(*ax_data.get_legend_handles_labels(), loc='center left')
```

**为什么**：数据面板保持干净，图例完整可见——优于 `bbox_to_anchor` 挪到画布外（后者浪费画布宽度且导出裁剪易翻车）。

**变体：图级底部图例条（2026-11-16 增补，收编自 figure_MACL @`0ddfbd3`）**：1×N 大面板组图不必逐轴 `legend()`——用 `fig.legend(handles=…, loc='lower center', bbox_to_anchor=(0.5, 0.01), ncols=len(handles))` 在整图底部铺一条共享图例，再以 `fig.tight_layout(rect=(0, 0.1, 1, 1))` 给它让位。图例句柄用 `Line2D([0], [0], label=展示名, **样式)` / `Patch(facecolor=…, label=…)` 手工构造，顺带完成"数据键 → 展示名"改名（内部键名对齐论文用语）与"仅图例换线型"的显示修正。与本库 `consolidate_shared_legends()`（plot_utils）同向：多面板系列语义相同时优先用现成函数，需要改名/改句柄样式时才手造。

## 模式三：分类柱隐藏 x 刻度

**何时用**：x 轴是"方法/条件"类别且图例已标识它们时（多方法 × 多指标矩阵）。

```python
ax.set_xticks([])   # 类别名交给图例/面板标题，不重复标
```

**为什么**：十几个方法名横排必然互相重叠或斜排难读；图例单独承担命名后 x 轴零噪音。注意：x 轴是连续数值时**禁止**用此模式。

## 模式四：动态 y 轴缩放

**何时用**：所有数值挤在窄区间（如 85~95）时，固定 0 起点会把差异压扁成"看起来都一样"。

```python
margin = data.std()          # 或 range 的小比例
ax.set_ylim(data.min() - margin, data.max() + margin)
```

**为什么**：比较差异是柱状图的本职；诚实前提是轴范围在图注中写明。竞赛论文答辩时"这图放大了差异"是加分操作而非造假（与截断 y 轴误导的区别：是否披露）。

**增补（2026-11-16，收编自 figure_MACL @`0ddfbd3`）**：上下限**向外取整到刻度步长**，避免"数据 87.3 → 上限 88.4"这类难读刻度——`ymax = 10 * ceil((vmax + 1) / 10)`、`ymin = 10 * floor((vmin - 1) / 10)`，再按量程物理边界夹住（如百分比夹在 0~100），随后 `ax.set_yticks(np.arange(ymin, ymax + 1, 10))`。**跨面板同指标对比时改用统一 ylim**：逐面板各自缩放会让"面板间谁高谁低"失真——先把全部面板的值汇成一组取公共范围（上游总览图 B/D 两组共 6 个子图即固定同一 y 范围）；逐面板动态缩放只用于"各 panel 讲各自指标"的场合。

## 模式五：边线 + hatch 打印安全分离

**何时用**：灰度打印/黑白复印后同色系柱子会糊成一片时——审稿人打印论文是常态。hatch 技法在 `matplotlib` 技能亦有覆盖（SKILL.md 图表增强清单、`references/plot_types.md` 代码示例；2026-09-10 复核更正，前次"全库零覆盖"查重结论有漏）；本模式的价值是**决策打包**——何时用、边线+hatch 二维分离的组合方式、与打印质检门禁的衔接。

```python
ax.bar(x, y, color=PALETTE["blue_main"], edgecolor='black', linewidth=2)
ax.bar(x, y2, color=PALETTE["blue_main"], hatch='/',  edgecolor='black')  # 同色不同纹
ax.bar(x, y3, color=PALETTE["blue_main"], hatch='.',  edgecolor='black')
```

**为什么**：色相在灰度转换后只剩明度差；黑边线提供硬轮廓，hatch 提供"纹理 × 明度"二维分离，双保险。hatch 纹理字典：`'/'` `'\'` `'.'` `'|'` `'-'` `'+'` `'x'` `'o'`。

**增补：hatch 兼作数据组判别（2026-11-16，收编自 figure_CellSpliceNet @`0ddfbd3`）**：配对柱（如"留一消融 vs 单模态对照"两组）同位置柱用同色，第二组整体加 `hatch='/'` 并配 `edgecolor='#555555'`——读者按**纹理归组**、按色相认角色，一张图讲清两组对照，不必拆两张图。柱内数值标签的底色自适应：按标签中心所在柱的真实填充色算感知亮度 `0.299R+0.587G+0.114B`（BT.601 加权，`#RRGGBB` 拆字节），<128 用白字否则黑字——与 SKILL.md"深色块内可用白字，但以文字中心所在真实块为背景判断"同规。

## 使用顺序建议

构图决策放在出图前（规划阶段读本文件选模式），而非出图后补救：
1. 多指标对比 → 模式一（超宽）+ 模式三（隐藏刻度）；
2. 方法多图例大 → 模式二（独立图例，或其图级底部图例条变体）；
3. 数值区间窄 → 模式四（动态 y 轴，跨面板同指标则统一范围）；
4. 要过打印关 → 模式五（边线+hatch）+ [semantic-palette.md](semantic-palette.md) 的 alpha 梯度；
5. 多次运行/多种子/多任务迹线 → §七-3（个体-聚合双线）+ §七-1（参考线分层）；
6. 柱顶标数值 → 先按 §七-4 算统一标注行与留白，再写画图代码。

## 六、多面板反冗余三原则（收编自 fig-academic @`1df9940`，Apache-2.0；2026-09-11 适应性改写）

多方法多指标组合图（`[2-panel]`/`[4-panel]`）规划时，在选完构图模式后过这三关：

**1. 反冗余三层递进**——每个 panel 必须回答**唯一**问题；遮住任一 panel 读者若无损失，该 panel 就是冗余：

| 层 | 问题 | 编码方式 |
|---|---|---|
| Overview 总览 | "整体模式是什么" | 堆叠柱/构成/总体分布 |
| Deviation 偏差 | "各组独有什么" | Z-score 热力图/发散色图/相对基线 |
| Relationship 关系 | "变量如何共变" | 散点/气泡/相关 |

典型冗余陷阱：绝对值+绝对值（同数据两种画法）→ 把其一改成偏差层；子集重复排名→合并或换成关系图；"不同视觉同一数据"（饼图+堆叠柱）→ 二选一。**终检四问**：同数据？同问题？可互相推导？去掉不动摇结论？——任一"是"即冗余。3 个信息致密的非冗余 panel 胜过 6 个有重复的。

**2. Hero Panel 原则**——每张多面板图要有且只有一个**主面板**：面积 1.2-1.5× 于辅助面板、居左上/居中最显眼位、用强调色（全图唯一允许高饱和处）、直接承载核心结论（审稿人看它 3 秒拿到主信息）。辅助面板更小、次级色、低饱和。

**3. 叙事排序**——panel 阅读顺序=左→右、上→下，**顺序就是故事**：数据证据在前、模型/示意图在后（示意图放 (a) 会暗示"这是推测"）；灵敏度/稳健性检验收尾。

## 七、参考线分层 · 个体-聚合双线 · 统一标注行（2026-11-16 收编自 figure_MACL / figure_RNAGenScape @`0ddfbd3`）

以下手法出自上游新增的 MACL 学习曲线组图、RNAGenScape 吞吐对比图，按本仓语境改写。

**1. 图层 zorder 约定**：网格 0 < 参考线 1 < 数据 3（标注 4）。参考线是"外部锚点"（零基准、专家上限、阈值线），不与数据系列混排；线型用自定义虚线元组 `(0, (8, 4))` 与数据系列区分——灰度打印下"虚线参考 + 实线数据"天然可分（呼应 [semantic-palette.md](semantic-palette.md) §〇① 的冗余编码要求）。

**2. 面板语义分界线**：训练阶段曲线在"训练到本任务"的那一步画 `ax.axvline(该步, color='#CFCECE', linewidth=2, zorder=0)`——竖线左侧读迁移、右侧读保持。把面板内要论证的分界直接画出来，读者不必从图注反推；同样思路适用于"干预前/后""阈值内/外"等任何二分语义。

**3. 个体-聚合双线（spaghetti + 粗均值线）**：多条同语义迹线（多任务/多种子/多次运行）先以 `alpha≈0.2、linewidth≈2、label='_nolegend_'` 画全部个体迹线，再叠一条 `linewidth≈5` 的聚合线承担图例与结论。适用于**迹线形状异质、置信带会把多峰抹平**的场合；迹线同质时仍优先本库 `uncertainty_band`（SKILL.md 随机实验合同）。注意每条个体迹线都要 `label='_nolegend_'`，否则图例会被塞满。

**4. 统一标注行**：一组柱顶数值标在**同一高度** `label_y = peak + max(2, 0.08*peak)`，且 **peak 必须把参考线值一并计入**（只看柱峰算 headroom，标注会压到更高的参考线）；rank 类面板 y 轴从 1 起，"遗忘/降幅"类保持零基线。这一条是 SKILL.md"图内标注不得压柱/压线"合同的具体落法。

**5. 跨数量级柱状**：吞吐/耗时横跨数量级时 `ax.set_yscale('log')` + **乘法留白** `ax.set_ylim(ymin, ymax * 50)`（给图例与标注让位）；数值标注用**乘法偏移** `ax.text(i, value * 1.4, f'{value:.3f}')`——log 轴上等距的是倍数，加法偏移会让矮柱标注贴死柱顶。配色示例即 [semantic-palette.md](semantic-palette.md) §一：本队方法深蓝锚点、基线淡彩降噪。

**6. 并列平均名次**：rank 面板按 `1 + 严格更优个数 + 0.5×(并列个数−1)` 计平均名次，避免"并列第一都记 1"高估；参比集合不同的两张图，名次不可跨图直读（图注声明参比集合）。
