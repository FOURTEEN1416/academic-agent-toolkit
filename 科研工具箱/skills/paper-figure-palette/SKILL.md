# 论文图表配色体系（paper-figure-palette v6）

一套已通过印刷实践检验的配色体系：**8 色分冷暖两族 + 4 色中性 + 同色系墨色**，
核心思想是"8 色只作大面积填充与色带，线条/文字交给深色墨色系统"，
配合灰度单调与色盲安全复核，保证彩色、灰度打印、色觉障碍三种介质下均可读。

## 2. 五条铁律（违反即返工）

1. **三层分工**：8 色只承担填充/色带/大面积；线条、描边、图例文字用墨色
   （`deepen(基色)` 或查 INK_MAP）；正文文字一律 INK。8 色对白底对比度仅
   1.3–2.1:1，**严禁直接作文字色或细线色**。
2. **深色用 `deepen()`，禁用 `darken()`**：darken 向黑等比缩放会同步砍彩度，
   得到浑浊深灰彩；deepen 固定 H°、压 L*、彩度取色域上限的 `INK_RATIO=0.65`
   倍，得到饱满同色系深彩。
3. **族内明度单调**：同一族内按 L*（或色相）单调入带/排序，灰度打印不出
   "假亮带"；族间用最大色相间隙切割（本板 90.8°→139.6°，隙 48.8°）。
4. **互补对立 + 邻近连续**：对立语义（温度↔水分）用互补对编码
   （TACC 54.6° ↔ M1 235.9°，相距 181°）；同一量的连续梯度只用同族邻近色。
5. **线型冗余编码**：多曲线并列时必须叠加线型差异
   （`-  --  -.  :  (0,(4,1,1,1))`），仅靠色相区分在灰度/色盲下不合格。

## 3. 新图上色工作流

1. **定性**：图里有哪些语义角色？主量/次量 → 两族锚色；强调 → TACC；
   判据/阈值 → CRIT；参考线 → NEU；文字 → INK。
2. **取色**：从 `scripts/palette_kit.py` 导入常量（`from palette_kit import *`），
   或查 §1 速查表；深色一律 `deepen(hex)`。
3. **色带**：热图/曲面用 `CMAP_TEMP` / `CMAP_MOIST`（LAB 感知均匀插值，
   近白起点 + 族内浅→深 + 设计深端）；**禁止 rainbow/jet**。
4. **排版**：按 `references/recipes.md` 的 rcParams 与 TikZ 样式块设置字号/网格/图例。
5. **体检**：`python scripts/palette_kit.py check` 全过；新配色修改后重跑。
6. **灰度/色盲抽查**：check 输出含灰度 L* 序与色盲最近色对距离，异常即调。

## 4. 配色诊断（用户说"不好看"时）

按 `references/color-system.md` §4 顺序排查，最常见的三个病灶：
① 发灰 = `ratio = C*/Cmax(L*,H°)` 低于 0.94（暖族）→ 提彩；
② 深色发浊 = 用了 darken 或黑色描边 → 换 deepen/墨色；
③ 整体乱 = 色相无族结构/超过两族 → 收拢为冷暖两族，多余色降级为 NEU。
改色只动 L* 与 C*，**色相 H° 一律不动**（保住用户已认可的色相语义）。
