# Problem Analysis Skill

## 用途
接到赛题后 1-2 小时内把题目"拆透"：题型判定、关键约束、坑点、答案形态。

## 触发时机
- 选题决策完成、确定做 A 或 B 或 C 题之后
- 距离比赛开始 0-2 小时

## 输入
1. 赛题 PDF（2026 真题，比赛 9/10 18:00 才发布）
2. 团队分工（编程/建模/写作）

## 输出
1. **题型判定**（6 类之一）：优化/预测/评价/统计/机理/图论
2. **3 个核心子问题**（Q1/Q2/Q3 拆分）
3. **关键变量清单**（已知量 + 未知量 + 约束）
4. **数据需求清单**（需要哪些公开数据 / 自带数据）
5. **坑点预警**（本题最容易翻车的 3 个地方）

## 强制分析流程
```
读题（30min）→ 题型判定（5min）→ 子问题拆分（20min）→ 变量清单（15min）→ 数据需求（10min）→ 坑点预警（10min）
总计 90 分钟硬性时间盒
```

## 题型判定 6 类
| 题型 | 标志词 | 默认模型 | 注意事项 |
|------|--------|----------|----------|
| **优化** | 最小/最大/最优/调度/分配/路径 | LP/IP/启发式 | 决策变量 + 目标 + 约束三件套 |
| **预测** | 预测/估计/未来/趋势/走势 | 时间序列/回归/ML | 训练/验证集划分 + 评价指标 |
| **评价** | 评价/排名/打分/比较/优劣 | AHP/TOPSIS/熵权法 | 指标体系 + 权重合理 |
| **统计** | 关系/影响/因素/差异/相关性 | 回归/方差/卡方 | 显著性 + 残差诊断 |
| **机理** | 机理/原理/机制/演化/扩散 | 微分方程/偏微分 | 模型假设 + 参数识别 |
| **图论** | 网络/路径/连接/最短/最大流 | 图算法/网络流 | 节点 + 边 + 权重 |

## 坑点预警模板（3 个最常见）
1. **数据缺失**：自带数据吗？是否要现场爬？爬不到怎么办？（备选数据源 2 个）
2. **模型复杂**：能不能用简单模型搞定？为创新而创新是大忌
3. **可解释性**：评委要的不是数字，是"为什么这么做"——必须能在论文里讲清楚机理

## 工具
- 用 `tools/model_recommender.py` 自动判定题型 + 推荐 3 套模型
- 无 Python 时直接对照上表手判

## 必填交付物
输出到 `work/analysis.md`，包含上述 5 个 section，1 页 A4 以内。

## 后续 Skill

- `model-building`：根据推荐模型 + 子问题建模型
