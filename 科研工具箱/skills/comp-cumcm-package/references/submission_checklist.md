# CUMCM 提交前核对清单（submission_checklist）

> **定位**：`pack_submission.py` 机检的**人工补充清单**——脚本查得了的硬项标【机检】，
> 脚本查不了的必须在这里逐项人工过一遍。来源：融合自检清单 **第五部分（论文电子版与支撑材料）**
> 与**第六部分（MD5 与上传）**。任何一项不过，**不要组包上传**。
>
> 用法：打印或在会话里逐项打勾；全部勾完后按第六部分时间节点执行上传。

## 一、论文电子版（第五部分）

- [ ] 【机检】论文电子版存在且为 PDF（`paper/main.pdf`）。
- [ ] 【机检】论文 ≤20MB、**不压缩**（超限先压图，不要降分辨率到不可读）。
- [ ] 【机检】首页必须是**摘要专用页**（第一页含"摘要"，不含标题页元素错位）。
- [ ] 【机检】PDF 文档属性（title/author/subject/keywords/creator/producer）**无身份线索**——
      ⚠️ hyperref 每次重编译会重写 title/subject/creator，**重编译后必须重新清元数据再打包**。
- [ ] 【人工】论文**内容与纸质承诺书版一致**（终稿后不要再动正文）。
- [ ] 【人工】论文**不含承诺书与编号专用页**（系统另收，勿订入正文 PDF）。
- [ ] 【人工】**第三页起页码连续**（第一页摘要、第二页编者规定页按赛区要求，页码从正文续）。
- [ ] 【人工】正文**无目录、≤30 页**（含附录；附录超页按赛区规则核对）。
- [ ] 【人工】附录含**支撑材料文件列表 + 全部完整可运行源程序**；
      没用到程序则注明"**本论文没有用到程序**"。

## 二、支撑材料（第五部分）

- [ ] 【机检】语料齐备：**源程序 + result*.xlsx + figures/*.json + AI工具使用详情.pdf**。
- [ ] 【机检】支撑材料合计 **≤20MB**。
- [ ] 【机检】路径（**文件夹名、文件名**）无身份线索——不要出现姓名/学校/拼音缩写命名。
- [ ] 【人工】支撑材料**内容与论文相符**（⚠️ 不符可能**取消评奖资格**，逐文件核对版本）。
- [ ] 【人工】源程序除附录外**同时放入支撑材料**，且能在常规环境复跑（说明运行方式）。
- [ ] 【人工】**承诺书、编号专用页未放进支撑材料**。
- [ ] 【人工】`AI工具使用详情.pdf` 与正文 AI 使用声明**口径一致**（用 comp-cumcm-disclosure 复核）。
- [ ] 【人工】打包前用 `--zip` 沙演一次：核对包内清单与上面各项一一对应。

## 三、MD5 与上传（第六部分）

- [ ] 【机检】计算**论文电子版**与**支撑材料包**各自的 MD5 并登记到交接文档。
- [ ] 【人工】正式包用 **WinRAR 压 .rar**（云南赛区要求；`--zip` 产物只是沙演件，不要上传）。
- [ ] 【人工】MD5 由**报名第一位学生**账号上传登记（见时间节点）。
- [ ] 【人工】上传后**回读复核**：重新下载/打开文件、比对 MD5 与页数，确认没有传错版本。
