# 语义调色板：颜色 → 数据角色映射（收编自 figures4papers）

> 来源：[figures4papers](https://github.com/ChenLiu-1996/figures4papers) `scientific-figure-making/references/design-theory.md` §3/§9，
> pinned commit `3c181f8`，License CC BY-NC-4.0。本地适应性改写（2026-09-09），见同目录 UPSTREAM.md。
> 与本技能现有 `setup_style()`（elegant 低饱和板）的关系：**不替换**。elegant 板回答"用哪些颜色"
> （本库竞赛论文口径），本文件回答"**什么角色用什么色**"——语义映射规则对任何具体色板都适用。

## 一、语义映射规则（通用层，优先级最高）

多系列对比图（本队方法 vs 基线）必须遵守，跨图保持一致：

| 角色 | 语义 | 色相方向 |
|------|------|---------|
| **本队方法 / 关键结果** | 读者视线锚点 | **蓝**系 |
| **改进 / 正向变体** | 增量收益 | **绿**系（由浅到深 = 完整度递增） |
| **基线 / 对比 / 替代方案** | 对照物 | **红**系（低饱和红粉，禁纯红 `#FF0000`，遵守本库色盲安全约束） |
| **参考 / 背景类别** | 不抢戏 | **中性灰**系 |
| **高亮** | 全图至多 1 处 callout | **金色**（唯一暖色强调，不与数据系列复用） |

检查问句：同一张消融图里"本队方法"是否始终同一个蓝？换图后基线是否还是同一个红？
读者不应需要重新学图例。

## 二、顶刊高对比 PALETTE（英文期刊 / AI 会议风格备选）

低饱和竞赛板不合适（导师要"顶刊感"或目标为 NeurIPS/CVPR 风格）时可用此板，
10 色即够常规对比图：

```python
PALETTE = {
    "blue_main":      "#0F4D92",  # 本队方法（锚点蓝）
    "blue_secondary": "#3775BA",  # 参考基线蓝
    "green_1":        "#DDF3DE",  # 改进·浅
    "green_2":        "#AADCA9",  # 改进·中
    "green_3":        "#8BCF8B",  # 改进·深
    "red_1":          "#F6CFCB",  # 对比·浅
    "red_2":          "#E9A6A1",  # 对比·中
    "red_strong":     "#B64342",  # 对比·强（替代基线）
    "neutral":        "#CFCECE",  # 中性灰
    "highlight":      "#FFD700",  # 高亮（至多 1 处）
}
```

## 三、消融研究编码：同色 alpha 梯度

消融/子组用**同一主色 + 不同 alpha**（0.2 → 1.0）表达"方法完整度"，
比多色更清晰地传达"这些都是同一个方法的变体"：

```python
for alpha, label in [(0.2, "w/o A"), (0.5, "w/o B"), (1.0, "full")]:
    ax.bar(x, vals, color=PALETTE["blue_secondary"], alpha=alpha, label=label)
```

## 四、打印安全（灰度区分）补充手段

本库质量底线已要求 grayscale-distinguishable；本源补充两个具体手法
（详见 [composition-patterns.md](composition-patterns.md) 模式五）：

- **黑边线**：`edgecolor='black', linewidth=1.5~3`——同色相邻柱的硬分离；
- **hatch 通道**：同色不同纹理 `'/'`、`'\\'`、`'.'`——灰度打印后靠纹理而非色相区分。

## 五、交叉校验调色板（外部输入收编，2026-09-10 · 非上游内容）

以下两套**不是替换而是交叉校验/场景备选**，均未经本库赛事实证，先少量试再用：

### 5.1 Okabe-Ito 实践组合（数据图 · 色盲安全口径）

来源：《十种期刊风格散点图！附代码》（微信公众号 mp.weixin.qq.com/s/MQ4Ci3-IjZrByisH_n0FMg，2026-08-06）——Okabe-Ito 色盲友好色系的工程实践组合。与本文件语义映射的对应：`#0072B2` 主数据蓝=本队方法锚点、`#D55E00` 朱红=对比强调、`"0.55"` 灰=参考线/背景。

| 色值 | 角色 | 配套参数 |
|------|------|---------|
| `#0072B2` | 主数据蓝（本队方法/主体散点） | s=42-46, alpha 0.68, 白描边 0.5 |
| `#56B4E9` | 置信带/辅助天蓝 | alpha 0.20 |
| `#D55E00` | 对比强调朱红（上调/界限虚线） | lw 1.6 |
| `#263238` | 主线/趋势线深灰蓝 | lw 2.0-2.2 |
| `#DCEEF8` | 一致性区间浅底带 | alpha 0.55 |
| `#B8C0C8` / `#AFB8C1` | 非显著背景点降级 | s=13, alpha 0.38-0.7, `rasterized=True` |
| `["#F5F8FB","#9CCBE5","#0072B2","#2A3F73"]` | 密度连续色带（近白→深藏青） | 单调感知均匀，替代彩虹 |
| 灰度 `"0.55"` | 一切参考线/阈值线 | 中性不抢主体 |

配套原则：整图颜色 ≤5 种；"上调/下调"类二元语义色**全图统一**（含边际面板同色）；密度图 cmap 必须单调感知均匀（反彩虹）；出图前过黑白打印/色盲模式/投影三场景。与本库 elegant 板的关系：作对照校验——若两组色板在同一语义角色上给出相近明度/色相，说明现板健康；冲突时以本库 elegant 板为准（竞赛口径已校准）。

### 5.2 国赛概念图写死配色（仅限 AI 生图/概念图，禁用于数据图）

来源：数模国赛 AI 生图与概念图提示词卡片（抖音截图组，2026-09-10 提取）。**边界**：只用于 AI 生成的技术路线/机制/架构/海报/图标类概念图；带坐标轴的数据图一律走 matplotlib + 本库色板（见 SKILL.md 概念图/数据图分家红线）。

- 流程/架构四段：`#10B981` 数据绿 · `#2563EB` 特征蓝 · `#7C3AED` 模型紫 · `#EA580C` 输出/冲击橙
- 结构件：`#333333` 箭头 · `#FFFFFF` 背景 · `#F7F7F7` 分组底 · `#F4F7FB` 海报底
- 学术强调对：`#2878B5` 学术曲线蓝（Science 风）· `#C82423` 强调红 · `#00468B` 图标线深蓝（Nature 风）
- `#00FF00` 仅作绿幕去背中间态，成品必须去背后才可入稿
