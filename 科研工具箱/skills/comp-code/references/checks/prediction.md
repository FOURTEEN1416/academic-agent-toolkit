# prediction.md — 预测类自检（时间序列/回归/分类）

> 目标：拦截预测任务四大翻车：数据泄漏、无基线、伪验证、区间失真。
> 配套手册：`skills/_utils/error_prevention.md` 三章（统计/回归/预测类）+ 八章（数据挖掘/机器学习类）。

## 1. 数据泄漏检查（最高优先级）

- [ ] 时间序列：训练集时间上严格早于测试集（禁止 shuffle 后随机切分时序数据）；任何滚动/ expanding 窗口验证中，特征工程（标准化、均值编码、缺失填充）在每折内独立拟合；
- [ ] 特征不含未来信息：滞后特征只用 t-1 及更早；目标编码/全局统计量在训练折内计算；
- [ ] 分组数据（同一对象多条记录）：按对象分组切分（GroupKFold），防"同一对象的记录同时在训练与测试集"；
- [ ] 标签本身可信：非代理标签（ID/文件名/行号冒充语义标签——validate_capability 应有对应断言）。

## 2. 基线对比（无基线的模型不予采信）

- [ ] 至少一个朴素基线：时序用 naive（上期值）/季节 naive；回归用均值/中位数；分类用多数类；
- [ ] 复杂模型对基线的提升量级写进 RESULTS.md；提升 <1% 时诚实说明（并检查是否过拟合噪声）；
- [ ] 基线与主模型用**完全相同的评估协议**（同一切分、同一指标、同一数据预处理口径）。

## 3. 验证协议正确性

- [ ] 时序：滚动原点（Rolling/Expanding）或单次按时间切分，k 折随机 CV 已排除；
- [ ] 测试集只碰一次：禁止"试多个模型挑测试集最好的"（这是把测试集当验证集用，属泄漏）——模型选择在验证集/交叉验证内完成；
- [ ] 超参搜索与最终评估分离，记录搜索空间与选中超参（可复现）。

## 4. 区间/不确定性（题面要求区间预测时）

- [ ] 预测区间有构造依据（残差分位 / 分位数回归 / bootstrap），不是"点预测 ± 手拍的数"；
- [ ] 区间覆盖率在验证集上实测并报告（名义 95% 的区间实测覆盖率应接近，过低 = 区间失真）。

## 5. 数值与凭证

- [ ] 指标与题面对齐（回归：RMSE/MAE/MAPE 哪个是题目问的；分类：准确率在类不平衡时的误导性已评估，报告 F1/AUC）；
- [ ] 无 NaN 进模型（缺失处理策略已声明并一致执行）；类别变量编码一致（训练与预测同映射）；
- [ ] validate_capability() 断言通过（如：去泄漏后指标显著优于随机/naive、金标准来源已声明）；
- [ ] RESULTS.md 有 AUDIT_OK 凭证（无硬约束题按 n_constraints=0 口径）。
