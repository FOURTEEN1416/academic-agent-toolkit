# 引用检查（Citation Check for CUMCM）

## 定位
国赛论文参考文献质量检查工具。覆盖：格式一致性、GB/T 7714 规范性、引用完整性、来源可信度评估。

## 依赖
- `sci-citation-management` — scientific-agent-skills 子 skill，通用引用管理
- Python 脚本 `tools/citation_checker.py`（本目录）

## 检查清单

### 1️⃣ 格式检查（GB/T 7714-2015）

| 类型 | 正确格式 | 常见错误 |
|------|----------|----------|
| 期刊论文 | `[1] 作者. 题名[J]. 刊名, 年, 卷(期): 起止页码.` | 缺卷/期/页码 |
| 教材 | `[2] 作者. 书名[M]. 版次. 出版地: 出版社, 年.` | 缺版次/出版地 |
| 学位论文 | `[3] 作者. 题名[D]. 城市: 学校, 年.` | 缺城市 |
| 会议论文 | `[4] 作者. 题名[C]. 会议名, 年: 页码.` | 格式混淆 |
| 网页/报告 | `[5] 作者. 题名[R/OL]. 网址, 发布日期.` | 缺日期 |

### 2️⃣ 引用完整性
- ✅ 文中引用与参考文献列表一一对应
- ✅ 无「断链引用」（引用[1]但参考文献无[1]）
- ✅ 引用连续（不会[1][3][5]跳跃）
- ✅ 无自引用/大量引用作者本人

### 3️⃣ 可信度评估（分数制）
| 来源 | 权重 | 说明 |
|------|------|------|
| SCI/EI 期刊 | ⭐⭐⭐⭐⭐ | 首选 |
| 中文核心 | ⭐⭐⭐⭐ | 可接受 |
| 普通期刊 | ⭐⭐⭐ | 慎用 |
| 教材/专著 | ⭐⭐⭐⭐ | 经典方法 |
| 学位论文 | ⭐⭐ | 一般不引 |
| 网页/博客 | ⭐ | 仅限数据来源 |

### 4️⃣ 参考文献数量参考（国赛）
- A 题（连续型）：10-15 篇
- B 题（离散型）：8-12 篇
- C 题（数据型）：12-20 篇
- D/E/F 题：8-15 篇

## 使用流程
```
写完参考文献 → 运行 citation_checker.py → 
修正格式错误 → 检查引用完整性 → 
评估可信度 → 补充不足 → 最终确认
```

## 国赛特殊要求
- 参考文献至少 8 篇，建议 10-15 篇
- 数学建模类优先引《数学建模算法与应用》等经典
- 国一论文的参考文献通常含近 3 年高水平论文
- 英文文献建议 30%-50%
- 不可引百度百科、CSDN 等非学术来源
- 格式不统一会扣分

## 调用方式
```powershell
skill("sci-citation-management")   # 通用引用管理
skill("citation-check")            # 国赛引用检查
python tools/citation_checker.py --input paper.md
```
