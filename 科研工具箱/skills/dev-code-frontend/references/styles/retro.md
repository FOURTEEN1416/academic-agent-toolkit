# 设计风格：复古（Retro）

适合有个性、怀旧主题、创意展示类项目。80/90 年代复古配色与质感。

## daisyUI 主题
`data-theme="retro"`。复古暖色调。

## 配色原则
- 复古暖色/低饱和的米黄、砖红、墨绿、褐色调。
- 对比鲜明但不刺眼，带年代感。
- 可用几种复古色搭配（比现代风更允许多色）。

## 字体层次
- 可用带个性的字体（衬线或复古无衬线），标题有"年代感"。
- 正文清晰即可，标题突出复古气质。

## 组件规格
- 圆角小或直角，带"实体感"。
- 卡片：实边框（可较粗）、偏硬的阴影（offset shadow / 类 neobrutalism 硬阴影可选）。
- 按钮：实心复古色 + 明显边框，点击有"实体按下"感。
- 可用像素/复古装饰元素点缀。

## 间距/布局
- 规整、有秩序的网格。
- 可带边框分隔的"分区"感。

## 禁忌
- ❌ 现代扁平的柔和渐变（与复古冲突）
- ❌ 过度精致的微妙阴影（复古要硬朗）
- ❌ 高饱和霓虹（除非明确要 vaporwave，一般复古是低饱和暖调）
