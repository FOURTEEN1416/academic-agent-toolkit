# 设计风格：极简专业（Minimal / Pro）

适合工具类、SaaS、后台、效率产品。冷静、克制、信息密度高、不花哨。

## daisyUI 主题
`data-theme="nord"`（或 `corporate`）。整站统一。

## 配色原则
- 深/中性画布为主，**单一强调色**只用在最重要元素（主 CTA、当前态、链接）。
- 大量中性灰阶做层次，禁止第二个鲜艳强调色。
- 语义色：主用 `base-100/200/300` + `base-content`，强调用 `primary`（一次）。

## 字体层次
- 无衬线（Inter / 系统默认）。
- 标题 600 字重 + 轻微负字距（紧凑）；正文 400 字重、行高 1.5。
- 层次靠字号+字重拉开，不靠颜色。

## 组件规格
- 圆角小而统一（6-8px），不要大圆角。
- 卡片：浅表面 + 1px 细边框（hairline），**深度靠边框和表面层次，不靠大阴影**。
- 按钮：主操作 `btn-primary`，次要 `btn-ghost`；内边距紧凑（8px 14px）。
- 输入框：细边框 + 聚焦时 2px 强调色描边。

## 间距/布局
- 4px 基准间距刻度（8/12/16/24/32）。
- 容器 `container mx-auto`，最大宽约 1200-1280px。
- 留白充足，区块间距大（48-96px）。

## 禁忌
- ❌ 多个鲜艳强调色堆叠
- ❌ 大面积渐变、光晕、装饰性阴影
- ❌ 花哨动画
- ❌ 圆角过大导致"玩具感"
