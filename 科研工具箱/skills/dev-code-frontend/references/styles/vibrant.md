# 设计风格：活泼多彩（Vibrant / Consumer）

适合面向大众的消费级产品、社区、电商、教育类。明快、友好、有活力。

## daisyUI 主题
`data-theme="cupcake"`（或 `emerald` / `lemonade`）。浅色明快。

## 配色原则
- 明亮浅色底，主强调色饱和鲜明（但仍以 daisyUI `primary` 为主）。
- 可有第二辅助色（`secondary`/`accent`）点缀，但不超过 2-3 个主色。
- 适度渐变可用在 Hero、按钮做点睛（不滥用）。

## 字体层次
- 友好的无衬线（Inter / Nunito 感觉），标题可略圆润。
- 标题字号大、字重足，营造亲和力；正文舒适行高 1.6。

## 组件规格
- 圆角偏大（12-16px），圆润友好。
- 卡片：浅表面 + 柔和阴影（可用，营造轻盈感）。
- 按钮：饱和主色实心、圆润；重要 CTA 可大号 `btn-lg`。
- 多用 `badge`、`avatar`、插图/emoji 增加活力。

## 间距/布局
- 宽松留白，卡片化组织，视觉轻松。
- Hero 区大标题 + 明快配图/渐变。
- 响应式友好，移动端触感舒适。

## 禁忌
- ❌ 灰暗压抑配色
- ❌ 过度信息密度（消费级要轻松）
- ❌ 颜色超过 3 个主色导致杂乱
- ❌ 生硬直角（活泼风要圆润）
